------------------------------------------------------------------------------------------
★ లగ్నము ( శరీర సౌఖ్యం )
   ప్రధాన కారకత్వం : శరీర సౌఖ్యం, రూపం, రోగ నిరోధక శక్తి, దేహ దారుఢ్యం.
   🟢 శుభ ఫలిత నియమం : మంచి బలమైన శరీరము, అందమైన రూపం, మంచి కొలతలు గల అంగసౌష్టవం కల్గియుండును.
   🔴 హెచ్చరిక నియమం  : బలహీనమైన దేహం, అంగలోపం, అనారోగ్యాలకు అనువుగా ఉన్న దేహం, అంగసౌష్టవం లేని దేహం లభించును.

★ ద్వితీయ స్థానము ( ధన స్థానము )
   ప్రధాన కారకత్వం : కుటుంబ అన్యోన్యత, వాక్ శుద్ధి, ధన చలామణి, నేత్రాలు.
   🟢 శుభ ఫలిత నియమం : కుటుంబ సౌఖ్యం, మంచి వాక్ శుద్ధి, నేత్ర సౌఖ్యం, ధన సమృద్ధి కల్గియుండును.
   🔴 హెచ్చరిక నియమం  : కుటుంబ కలహాలు, కంటి చూపు సమస్యలు, మాటలో కఠినత్వం, ధన నష్టములు కలుగును.

★ తృతీయ స్థానము ( భాతృ స్థానము )
   ప్రధాన కారకత్వం : కనిష్ట సోదర సోదరీలు, ధైర్యోత్సాహాలు, దగ్గర ప్రయాణాలు, చెవులు, చొరవ తీసుకొనే స్వభావం.
   🟢 శుభ ఫలిత నియమం : తోబుట్టువుల సహకారం, ధైర్యసాహసాలు, విజయాలు కల్గియుండును.
   🔴 హెచ్చరిక నియమం  : తోబుట్టువులతో విరోధము, భయము, పరాజయములు, కంఠ సంబంధ సమస్యలు కలుగును.

★ చతుర్థ స్థానము ( మాతృ స్థానము )
   ప్రధాన కారకత్వం : గృహము, వాహనం, గృహవసతులు, స్థిరాస్తి, బంధుమిత్రులతో సంబంధం, దాసదాసీ జనం.
   🟢 శుభ ఫలిత నియమం : మాతృ సౌఖ్యం, సొంత ఇల్లు, వాహన యోగము, స్థిరాస్తులు కల్గియుండును.
   🔴 హెచ్చరిక నియమం  : తల్లికి అనారోగ్యం లేదా విరోధం, గృహ వాహన నష్టములు, సుఖము లోపించును.

★ పంచమ స్థానము ( పుత్ర స్థానము )
   ప్రధాన కారకత్వం : విద్య గ్రాహక శక్తి, మార్గ దర్శకుడు, సలహా దారు, మంత్రి, సత్ సంతానం, స్వగ్రామం.
   🟢 శుభ ఫలిత నియమం : మంచి సంతానం, మంత్రి పదవి, వివేకము, వినయము, పాండిత్యం, గ్రంథ రచనలో ప్రావీణ్యం కలుగును.
   🔴 హెచ్చరిక నియమం  : పుణ్యమును అందించదు, కానీ పాపము లేదు కనుక చెడు చేయదు. ఫలితాలు సామాన్యంగా ఉండును.

★ షష్టమ భావం ( శత్రుస్థానము )
   ప్రధాన కారకత్వం : శత్రువులు, ఋణాలు, రోగాలు, అనుమానాలు, అవమానాలు, అపనిందలు.
   🟢 శుభ ఫలిత నియమం : శత్రు, ఋణ, రోగ సమస్యలు ఉండవు. వడ్డీ వ్యాపారం లేదా వైద్యవృత్తితో ధనార్జన కలుగును.
   🔴 హెచ్చరిక నియమం  : శత్రు, ఋణ, రోగ సమస్యలు జీవితమంతా వేధించవచ్చు. మనోచింత, అపవాదులు, అప్పుల చిక్కులు ఉండును.

★ సప్తమ భావం ( కళత్ర స్థానము )
   ప్రధాన కారకత్వం : భాగస్వామ్యం, ఆహారం, విహారం, నిద్ర, వివాహము, నియంత్రిత జీవనం.
   🟢 శుభ ఫలిత నియమం : కళత్రము నుండి సుఖము, ఆకర్షణీయమైన భార్య/భర్త, ధనము, ఇతర సుఖములు సకాలంలో లభించును.
   🔴 హెచ్చరిక నియమం  : భార్య/భర్త సౌఖ్యం ఉండదు, వివాహ సమస్యలు, మనోశాంతి లేకపోవడము. ఒకవేళ 8వ స్థాన దోషముంటే ఆత్మహత్య ప్రేరణ.

★ అష్టమ భావం ( ఆయుస్థానము )
   ప్రధాన కారకత్వం : ఆయుష్షు, గెలుపు ఓటములు, కోర్టుకేసులు, ఆకస్మిక సంఘటనలు.
   🟢 శుభ ఫలిత నియమం : దీర్ఘాయువు, పుష్టి కలిగిన శరీరం, వీర్యపుష్టి, సౌఖ్యములు కల్గును. అకాల మృత్యు భయం ఉండదు.
   🔴 హెచ్చరిక నియమం  : అల్పాయుష్కుడగును, అకాల మృత్యువు, కారాగార ప్రాప్తి, పరాభవములు కలుగును. కామవాంఛ లోపించును.

★ నవమ స్థానము ( పితృ స్థానము )
   ప్రధాన కారకత్వం : తండ్రితో మంచి సంబంధం, పిత్రార్జితము, తీర్థయాత్రలు, దైవభక్తి, శుభకార్యాలు, పుణ్యకార్యాలు.
   🟢 శుభ ఫలిత నియమం : తండ్రి ఆస్తి లభించును, సకల ఐశ్వర్యములు, నిలువయుండే ధనము, భాగ్యము, దైవభక్తి కల్గును.
   🔴 హెచ్చరిక నియమం  : నిర్భాగ్యుడగును, తీవ్ర పేదరికం, దైవభక్తి లోపం, ఆస్తి నష్టములు కలుగును.

★ దశమ స్థానము ( జీవన స్థానము )
   ప్రధాన కారకత్వం : కీర్తి, గౌరవము, వృత్తి, ఉద్యోగం, స్వయార్జితం.
   🟢 శుభ ఫలిత నియమం : ఉన్నత వృత్తి, రాజకీయ పదవులు, కీర్తి గౌరవము, అష్టభోగములు. నిగ్రహశక్తి కలిగిన జీవితం.
   🔴 హెచ్చరిక నియమం  : జీవనమునకు నిరంతర పోరాటం, గౌరవ లోపం, వృత్తిలో ఇబ్బందులు ఎదురవుతాయి.

★ ఏకాదశ స్థానము ( లాభ స్థానము )
   ప్రధాన కారకత్వం : జ్యేష్ఠ సోదర సోదరీలు, రాబడి, అక్రమ సంపాదనం, దోపిడీలు.
   🟢 శుభ ఫలిత నియమం : వివిధ రూపాలలో ఆదాయం, లాటరీ లాభాలు, కట్నకానుకలు, భారీ ధన లాభములు కలుగును.
   🔴 హెచ్చరిక నియమం  : ఆదాయంలో ఆటంకాలు, లాభాల్లో నష్టాలు, తండ్రి ఆస్తి నష్టం, దుర్వ్యసనాలు కలుగును.

★ ద్వాదశ స్థానము ( వ్యయ స్థానము )
   ప్రధాన కారకత్వం : ఖర్చులు, మోక్ష స్థానం, ఊర్ధ్వలోకాలు, దైవ భక్తి, సునాయాస మరణం లేదా దుర్మరణం.
   🟢 శుభ ఫలిత నియమం : మంచి కార్యాలకు ఖర్చు, ఆధ్యాత్మిక చింతన, మరణ సమయమున సుఖము, స్వర్గలోక ప్రాప్తి.
   🔴 హెచ్చరిక నియమం  : బంధువులు లేని అనాధ చావు, దుర్వినియోగమయ్యే ఖర్చులు, నిరాశతో కూడిన మరణం.

    - హెచ్చరిక : ధన లోపం వల్ల, కుటుంబంలో ఉన్న చిక్కుల వల్ల, శరీర బాధ.
• [BHAVA_LORD_1_3] 1వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : చెల్లెల్లు, తమ్ముళ్ళ పోషణతో శరీర బాధ, నిద్ర లేకపోవటం, అలసి పోవటం, ఉత్సాహం లేకపోవడం.
• [BHAVA_LORD_1_4] 1వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : భూ, గృహ, వాహన సౌఖ్య సమృద్ధి వల్ల శరీర సౌఖ్యం, సుకుమారంగా పెరగడం, తల్లి గారాబం, శరీర అలంకరణ.
    - హెచ్చరిక : తల్లి వలన నిద్ర పట్టకుండా శరీరం కృశించుట, సేవకుల వల్ల, బంధుమిత్రులవల్ల చికాకులు. పెంపుడు జంతువుల వల్ల ఇబ్బంది.
• [BHAVA_LORD_1_5] 1వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : చూస్తే పండితుడిలా, విద్యావంతుడిలా కనిపించటం, పిల్లల వల్ల శరీర సౌఖ్యం.
• [BHAVA_LORD_1_6] 1వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రువులని అణచ గలిగే అంత బలం, రోగ నిరోధక శక్తి, ఋణాలని తెచ్చుకునే ధైర్యం.
    - హెచ్చరిక : శత్రువుల చేత శరీర బాధ, గాయాలు, రోగాల వల్ల శరీర అసౌకర్యం.
• [BHAVA_LORD_1_7] 1వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : ఆహార, విహార, నిద్ర సరిగా లేకపోవడం వల్ల శరీర సహకరించకపోవడం, భార్యాబిడ్డలను పోషించటంలో శరీరం కృశించిపోవటం.
• [BHAVA_LORD_1_8] 1వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : పోటీల్లో విజయం వల్ల పేరు ప్రఖ్యాతులు, శారీరకంగా ఉత్సాహం పొందటం, స్త్రీ సౌఖ్యం, ప్రమాదాలని తప్పించుకొని శరీరం కాపాడుకోవడం.
    - హెచ్చరిక : ఆకస్మిక ప్రమాదాలు, అపనిందలు, అవమానాలు, అపజయం వల్ల శరీర కృశించుట, పోటీలో ఓడిపోవడం వల్ల శరీర బాధ.
• [BHAVA_LORD_1_9] 1వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : మంచి భక్తుడిలా, ధార్మిక వ్యక్తిలా ఉంటారు, పెద్దలంటే గౌరవం, నిల్వధనం వల్ల శరీర సౌఖ్యం.
• [BHAVA_LORD_1_10] 1వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : వృత్తి, ఉద్యోగ, వ్యాపారాదుల్లో ఆదాయం దినదినాభివృద్ధిగా ఉండి శరీర పోషణ, శరీర అలంకరణ.
    - హెచ్చరిక : వృత్తి, ఉద్యోగ, వ్యాపారాదుల్లో ఒత్తిడి, అధిక శ్రమ, గుర్తింపు లేకపోవడం వల్ల శరీర అలసట.
• [BHAVA_LORD_1_11] 1వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : అక్కలు అన్నల వల్ల శారీరక శ్రమ, అవినీతికి పట్టుబడటం వలన శరీర బాధ, వృధా శారీరక శ్రమ చివరికి లాభాలు రాకపోవడం.
• [BHAVA_LORD_1_12] 1వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : మోక్షసాధన వలన తేజోవంతమైన శరీరం, పరోపకారం వల్ల శరీర పోషణ, ఖర్చులు సద్వినియోగం వల్ల శరీర సౌఖ్యం.
    - హెచ్చరిక : దుష్ట సాంగత్యం వల్ల చెడు అలవాట్లు, ఖర్చులు దుర్వినియోగం వల్ల శరీరానికి అసౌఖ్యం.

=== 2వ భావం (ధన భావం - ధనం & కుటుంబం) ===
• [BHAVA_LORD_2_1] 2వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : నేత్ర సౌఖ్యం, వాక్ నైపుణ్యం, దేహ దారుఢ్యం వల్ల ధన చలామణి, కుటుంబ సభ్యుల ఆరోగ్యం వల్ల కుటుంబ అన్యోన్యత.
• [BHAVA_LORD_2_2] 2వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : వాక్ చాతుర్యంచే, సమయ స్ఫూర్తిచే, కుటుంబ సభ్యులను, వీధిలో వారిని మెప్పించుట.
    - హెచ్చరిక : నోటి దురుసువల్ల ధనాన్ని కోల్పోవుట, అసత్యాలని మాట్లాడుట వల్ల కుటుంబ విరోధాలు, విభేదాలు, ధన సహాయం లేకపోవడం.
• [BHAVA_LORD_2_3] 2వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : దాయాదుల వలన కుటుంబ అన్యోన్యత దెబ్బతినడం, కుటుంబాన్ని రక్షించడానికి ధైర్యోత్సాహాలు లేకపోవటం.
• [BHAVA_LORD_2_4] 2వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : మంచి బంధు మిత్రులు, ధన చలామణి, సేవకులు, బలగం
    - హెచ్చరిక : భూ పంపకాల వల్ల తగాదాలు, వాహనాల వలన, సేవకుల వలన కుటుంబ అన్యోన్యత గాని, ఎదురింటివారితో గానీ సంబంధం దెబ్బతినుట.
• [BHAVA_LORD_2_5] 2వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : సత్ సంతానం వలన, గ్రామంలో పలుకుబడి వలన కుటుంబ అన్యోన్యత పెరగడం, విద్యాబలం వలన అవసరానికి ధనం చేకూరడం.
• [BHAVA_LORD_2_6] 2వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రువుల వలన కుటుంబ ఐక్యత పెరగడం, అప్పుతీసుకున్న వారు తిరిగి ఇవ్వడం.
    - హెచ్చరిక : శత్రు బాధ, కుటుంబ అన్యోన్యత ఉండదు, వాక్శుద్ధి కోల్పోవడం, చేతిలో డబ్బు ఉండదు.
• [BHAVA_LORD_2_7] 2వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : అకాల ప్రయాణం, అకాల నిద్ర, ఆహారం, కుటుంబ కలహాలు, భోజన లోటు, భార్య వలన బాధలు.
• [BHAVA_LORD_2_8] 2వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : గెలవటం వల్ల కుటుంబ అన్యోన్యత, అష్ట భోగములు, నేత్రానందం, వీధిలో గౌరవము, హోదా.
    - హెచ్చరిక : నిందాపవాద, పరాభవం, కుటుంబ కలహాలు, ధన చలామణి తగ్గుట,
• [BHAVA_LORD_2_9] 2వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : భక్తుడు కాబట్టి ధన చలామణి, పితృని వల్ల అన్యోన్యత పెరగడం, దాన ధర్మాలు చేయటం, తీర్థ యాత్రల వలన కుటుంబ అన్యోన్యత.
• [BHAVA_LORD_2_10] 2వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : అధికారుల అండ, కుటుంబ సౌఖ్యం, పాలన శక్తి యుక్తులు, ధన చలామణి పెరగటం.
    - హెచ్చరిక : ఉద్యోగం కోల్పోవటం వలన ఇంట్లో గొడవలు.
• [BHAVA_LORD_2_11] 2వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : లాటరీల్లో, షేర్లలో ధనం కోల్పోవడం, లంచం ఇచ్చి పనులు జరుగక పోవడం, అక్కలు, అన్నయ్యల మోసం, వారి మాట నిల బెట్టుక పోవడం.
• [BHAVA_LORD_2_12] 2వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : మోక్ష మార్గం వలన ధన చలామణి, అనవసర ఖర్చులు చేయకపోవటం వలన కుటుంబ అన్యోన్యత, మాటకు విలువ.
    - హెచ్చరిక : ధన దుర్వినియోగం వలన కుటుంబ అన్యోన్యత దెబ్బతినటం, మాటకు విలువ లేకపోవడం.

=== 3వ భావం (భ్రాతృ భావం - సోదరులు & ధైర్యం) ===
• [BHAVA_LORD_3_1] 3వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : దేహబలం కలిగిన కనిష్ట సోదర సోదరీలు, ధైర్యముచే కలిగిన కనిష్ట సోదర సోదరీలకు అండగా ఉండుట.
• [BHAVA_LORD_3_2] 3వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : వాక్కు వలన, ధనచలామణి వలన, కుటుంబ అన్యోన్యత వలన కనిష్ట సోదర సోదరీలకు అనుకూలంగా ఉండును.
    - హెచ్చరిక : మాట దురుసుతనం వలన కనిష్ట సోదర సోదరీల వ్యతిరేకత.
• [BHAVA_LORD_3_3] 3వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : ధైర్య సాహసాలు లోపించడం, దగ్గర ప్రయాణాల్లో ప్రయాస, చెడు వార్తలు వినుట.
• [BHAVA_LORD_3_4] 3వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : భూ, గృహ, వాహనాలతో బంధువుల సఖ్యత, తల్లి సహాయం వలన కుటుంబ అన్యోన్యత, స్థిరాస్తులు, బంధుమిత్రుల వలన ధైర్య సాహసాలు.
    - హెచ్చరిక : భూ, గృహ, వాహనాలతో బంధువుల తగాదాలు, బంధు మిత్రులు, సేవకుల వలన కుటుంబం లో గొడవలు, ధైర్యోత్సాహాలు తగ్గడం.
• [BHAVA_LORD_3_5] 3వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : సమయస్ఫూర్తి, మేధాశక్తి, సంతానం వలన, చెల్లెళ్ళు తమ్ముళ్ళతో మంచి సంబంధం పెరగడం.
• [BHAVA_LORD_3_6] 3వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రువులపై ధైర్యసాహసాల వలన కనిష్ట సోదర సోదరీల అన్యోన్యత, శుభ వార్తలు వినడం.
    - హెచ్చరిక : శత్రువుల వలన కనిష్ట సోదర సోదరీలతో గొడవలు, చెడు వార్తలు వినడం.
• [BHAVA_LORD_3_7] 3వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : భార్య వలన, భాగస్వాముల వలన, దుర్వ్యసనాల వలన కనిష్ట సోదర సోదరీవర్గం వారితో విభేదాలు, వీటి వలన ధైర్యోత్సాహాలు తగ్గడం.
• [BHAVA_LORD_3_8] 3వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : అవినీతిని ఎదుర్కొనడానికి ధైర్యోత్సాహాలు, ప్రయత్న కార్య విజయం, పోటీల్లో విజయం వలన దాయాదుల అనుకూలత.
    - హెచ్చరిక : ఆకస్మిక ధుస్సంఘటనలు, నిందపవాదులు, ప్రయత్న కార్య భంగం, అవినీతిని ఎదుర్కొబోయి విఫలం. దాంపత్య సుఖము భంగం.
• [BHAVA_LORD_3_9] 3వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : తండ్రి వలన, ధర్మ కార్యాల వలన కనిష్ట సోదర సోదరీల మంచి సంబంధం, గురుభక్తి, దైవ భక్తి వలన ధైర్యోత్సాహాలు.
• [BHAVA_LORD_3_10] 3వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : ఉద్యోగం, కీర్తి గౌరవాల వలన తమ్ముళ్ళు చెల్లెళ్ళ అనుకూలం.
    - హెచ్చరిక : ఉద్యోగం లేకపోవడం వలన, ఉద్యోగ మార్పు వలన తమ్ముళ్ళు చెల్లెల్లు ఆదరించకపోవడం. పై అధికారుల కోపం వలన వ్యతిరేకత.
• [BHAVA_LORD_3_11] 3వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : దురాదాయ దుర్లాభాలకు ప్రయత్నించి భంగ పడటం, నష్టపోవడం, జ్యేష్టా సోదర సోదరీల వల్ల నష్టపోయి తమ్ముళ్ళ చెల్లెళ్ల దూరం.
• [BHAVA_LORD_3_12] 3వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : సద్ వ్యయం వల్ల తమ్ముళ్ళు చెల్లెళ్ల అనుకూలత.
    - హెచ్చరిక : ధన వృధా చేయుటం వల్ల తమ్ముళ్ళు చెల్లెళ్ళ దూరం.

=== 4వ భావం (మాతృ/గృహ భావం - తల్లి, గృహం, వాహనం) ===
• [BHAVA_LORD_4_1] 4వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : స్వయం కృషి వలన భూ, గృహ, స్థిరాస్తి వృద్ధి చేయుటం.
• [BHAVA_LORD_4_2] 4వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : వాక్ శుద్ధి, వాక్ నైపుణ్యం, ధన చలామణి వలన బంధుమిత్రుల మంచి సంబంధం, సేవకులు గౌరవించటం.
    - హెచ్చరిక : దురుసు వాక్కు వలన బంధుమిత్రులను, సేవకులను దూరం చేసుకోవడం, కుటుంబ అన్యోన్యత లేకపోవడం వల్ల మిగిలిన వారు దూరం.
• [BHAVA_LORD_4_3] 4వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : దాయాదుల వలన, భూమి, వాహనం, గృహం వలన చిక్కులు, ధైర్యం లోపించటం, దగ్గర ప్రయాణాల్లో నష్టం.
• [BHAVA_LORD_4_4] 4వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : తల్లి సూచనల వలన స్థిరాస్తి అభివృద్ధి, నూతన గృహ నిర్మాణం. బంధుమిత్రులు, సేవకులు మంచి విశ్వాస పాత్రులుగా ఉండటం.
    - హెచ్చరిక : తల్లి వలన గాని,బంధుమిత్రుల వల్ల గాని స్థిరాస్తి అమ్కాల్సి వస్తుంది.గృహ నిర్మాణానికి ఆటంకాలు కలగటం. బంధుమిత్రులు,సేవకుల వల్ల చిక్కులు
• [BHAVA_LORD_4_5] 4వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : విద్యాబలం, వివేకం చేత భూమి , వాహన , గృహ ప్రాప్తి. సంఘ సేవ కార్యాల ద్వారా తల్లిని ఆనందింప చేయడం.
• [BHAVA_LORD_4_6] 4వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రువులపై జయం, స్థిరాస్తి తగాదాల్లో విజయం, అప్పులు వసూలు అవడం ద్వారా బంధుమిత్రుల సంబంధం పెరగడం.
    - హెచ్చరిక : శత్రు,ఋణ,రోగాల వల్ల స్థిరాస్తి తరుగుదల,బంధుమిత్రుల విరోధం,శత్రువుల వలన స్థిరాస్తి పోతుందని భయం. కుటుంబ సభ్యుల అనారోగ్యం.
• [BHAVA_LORD_4_7] 4వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : భార్య మూలకంగా బంధువుల సంబంధం చెడటం, భాగస్వాముల వలన స్థిరాస్తి అమ్ముకోవడం. వీరి వల్ల అకాల నిద్ర, ఆహార, ప్రయాణాలు.
• [BHAVA_LORD_4_8] 4వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : తక్కువ ధరకే గృహ కొనుగోలు, కోర్టు వ్యవహారాల్లో బంధుమిత్రులకు సహాయం వలన వారి సంబంధం వృద్ధి. నిర్మాణాలకు ఆయుష్షు.
    - హెచ్చరిక : కోర్టుకెసుల్లో ఓడిపోవటం వల్ల భూమి,వాహన,స్థిరాస్తి అమ్మటం,దొంగిలించబడటం. భయంతో గృహం వదిలి పారిపోవడం, కారాగార వాసం.
• [BHAVA_LORD_4_9] 4వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : తల్లి,తండ్రుల వలన భూ,గృహ,వాహన అభివృద్ధి. నిధినిక్షేపాలు లభించే అవకాశం. శుభకార్యాలకు , తీర్థ యాత్రలకు బంధుజన సౌఖ్యం.
• [BHAVA_LORD_4_10] 4వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : ఉద్యోగం, కీర్తి గౌరవాల వలన బంధుమిత్రుల ఆదరణ, స్వయార్జితం వలన భూ,గృహ,వాహన వృద్ధి,
    - హెచ్చరిక : ఉద్యోగం వదిలివేయడం వలన గౌరవ మర్యాదలు పోగొట్టుకోవడం, బంధుమిత్రులకి దూరం అవటం, స్థిరాస్తి అమ్ముకోవడం.
• [BHAVA_LORD_4_11] 4వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : ఆకస్మిక లాభాపేక్షతో భంగపడటం,అవివేకం వలన స్థిరాస్తి కోల్పోవడం, అక్కాఅన్నలు, ఆప్త మిత్రుల కోసం స్థిరాస్తులు అమ్ముకోవడం.
• [BHAVA_LORD_4_12] 4వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : పరోపకారం, పొదుపు వలన స్థిరాస్తి పెంపు. సత్ సాంగత్యం వలన బంధుమిత్రుల మంచి సంబంధం,
    - హెచ్చరిక : ధన దుర్వినియోగం వలన స్థిరాస్తి తరుగుదల, అమ్ముకోవడం, బంధుమిత్రులు దూరం అవడం.

=== 5వ భావం (పుత్ర/బుద్ధి భావం - సంతానం, విద్య, మేధస్సు) ===
• [BHAVA_LORD_5_1] 5వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : సంతాన అభివృద్ధి, స్వయం కృషిచే గ్రామంలో అగ్రగణ్యుడు అగుట.
• [BHAVA_LORD_5_2] 5వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : వాక్కుచే, ధనచలామణి వలన గ్రామంలో మంచి పేరు, పలుకుబడి.
    - హెచ్చరిక : దురుసు వాక్కు వలన కుటుంబంలో చెడ్డపేరు, గ్రామం లో వ్యతిరేకత, పిల్లలను త్రైతించడం, వీధిలో వారి కారణంగా పిల్లలు చెడిపోవడం.
• [BHAVA_LORD_5_3] 5వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : గ్రామంలో అగౌరవం, దాయాదుల వల్ల పిల్లలు చెడిపోవడం, ఆపదలు, గ్రామాంతరవాసం, చెడు వార్తలు వినడం వల్లి గ్రామం వదిలి వెళ్లడం.
• [BHAVA_LORD_5_4] 5వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : తల్లి వలన విద్యావకాశం, బంధుమిత్రులు, సేవకుల వల్ల గ్రామాధికారం, గ్రామాభివృద్ధికి తోడ్పడే నిర్మాణాలు, గ్రంథపరిశోధన, సంతానాభివృద్ధి.
    - హెచ్చరిక : పిల్లలకి మాతృ ప్రేమ తగ్గుతుంది, భూ,గృహ,వాహన, స్థిరాస్తికి సంబంధించిన సమస్యల వలన మానసిక క్షోభ, మానసిక అశాంతి.
• [BHAVA_LORD_5_5] 5వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : సంతానాభివృద్ధి, గ్రామంలో మేధావిగా పేరుగాంచుట, గ్రామ శ్రేయస్సుకి కృషి చేయుట, విద్యా విజ్ఞానం ద్వారా సహృదయుడుగా పేరుగాంచుట
• [BHAVA_LORD_5_6] 5వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రువులను జయించడం వలన గ్రామంలో పలుకుబడి, ఋణాలు సకాలంలో వసూలు అగుట వల్ల విద్యకి ఆటంకాలు రాకపోవటం.
    - హెచ్చరిక : శత్రు, రోగ, ఋణాల వల్ల మనః శాంతి ఉండకపోవడం, సంతానాభివృద్ధి లోపించడం, గ్రామాధికారానికి ప్రాకులాడి విరోధాలు తెచ్చుకోవడం.
• [BHAVA_LORD_5_7] 5వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : భార్య వల్ల గాని, అకాల నిద్ర, భోజన, ప్రయాణాల వల్ల గాని మానసిక అశాంతి, గ్రామస్థుల వ్యతిరేకతలు, వ్యాపార భాగస్వాములతో పేచీ.
• [BHAVA_LORD_5_8] 5వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : వ్యావహారిక జయము, గ్రామంలో అన్యాయం ఎదురించి పేరు తెచ్చుకోవడం, గెలుపుల వలన సంతానాభివృద్ధి.
    - హెచ్చరిక : ఆకస్మిక ప్రమాదములచే సంతానముకకు బాధలు, పరాభవ దుఃఖములు, మందబుద్ధి కలిగి గ్రామాంతరవాసము చేయుట.
• [BHAVA_LORD_5_9] 5వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : దైవ కార్యములు, పుణ్యక్షేత్ర సందర్శనము, సద్గురువుల అనుగ్రహము, మానసిక ప్రశాంతత కలుగును,సంకల్ప శుద్ధి,మంత్రోపాసన ఫలించును.
• [BHAVA_LORD_5_10] 5వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : పాలనా శక్తి యుక్తులతో గ్రామాధికారం పొందుట, వృత్తి, ఉద్యోగ, వ్యాపారానందు సామర్థ్యం పెరిగి సంతానం అభివృద్ధి కలుగును.
    - హెచ్చరిక : వృత్తి, ఉద్యోగ, వ్యాపారానందు ఆదాయం తగ్గటం వలన సంతానమునకు కష్టo, పెద్దల ఆగ్రహం వలన మనఃశాంతి లోపించుట.
• [BHAVA_LORD_5_11] 5వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : వివేక శూన్యుల సాంగత్యంచే, మందబుద్ధిచే గ్రామచిక్కులు, దుష్టజన సహవాసియై గ్రామప్రజల వ్యతిరేకత పొందుట, సంతానముకు కష్టము
• [BHAVA_LORD_5_12] 5వ భావాధిపతి → 12వ భావము నందు స్థితి

    - హెచ్చరిక : ధనం దుర్వినియోగం చేయుట, ఇతరులకు కీడు చేయుటచే గ్రామస్తుల ఆగ్రహమునకు గురిఅగుట, సంతానము దుర్వ్యసనాల పాలుగుట.

=== 6వ భావం (శత్రు/రోగ భావం - శత్రువులు, ఋణాలు, ఆరోగ్యం) ===
• [BHAVA_LORD_6_1] 6వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : రోగనిరోధక శక్తి, శారీరక బలం చేత శత్రువులను జయించడం, ఇతరులకు అప్పు ఇచ్చి ఆదుకోవటం.
• [BHAVA_LORD_6_2] 6వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : కుటుంబ సభ్యుల ప్రోత్సాహంతో అప్పు తీర్చుట, ధన బలంతో శత్రువులను లోబరచుకోవడం.
    - హెచ్చరిక : మాట దురుసుతనంచే విరోధములు,ధనచలామణి లోపముచే ఋణములు చేయుట,కుటుంబంలో విరోధాలు,కుటుంబ ఖర్చు నిమిత్తం అప్పు.
• [BHAVA_LORD_6_3] 6వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : గృహమునందు వినోద వస్తువులకై అప్పు చేయుట, దాయాదుల వల్ల విరోధములు, వారి వల్ల అప్పు, శత్రు రోగ చిక్కులు ఎదుర్కొనుట.
• [BHAVA_LORD_6_4] 6వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : భూ,గృహ,వాహన ఆదాయంచే ఋణ విముక్తి, బంధుమిత్ర సేవక బలంచే శత్రువుల మీద విజయం, మాతృ వర్గం వలన శత్రుజయము.
    - హెచ్చరిక : బంధుమిత్రుల వలన,భూ,గృహ,వాహనాదుల వల్ల శత్రువులు ఏర్పడుట,మాతృమూలకముగా విరోధము,నూతన నిర్మాణములకు అప్పుచేయుట
• [BHAVA_LORD_6_5] 6వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : గ్రామ ప్రజల అండ దండలతో మేధాశక్తియుక్తులతో సంతాన సహకారముతో శత్రువులను దెబ్బతీయుట,పాండిత్యముచే ఇతరులనుకాపాడుట
• [BHAVA_LORD_6_6] 6వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : వడ్డీ వ్యాపారం ద్వారా ధన సంపాదన, శత్రు ఋణ రోగ బాధలు తొలగించడం.
    - హెచ్చరిక : శత్రువృద్ధి,ఆకస్మిక విపత్తులు,నిరంతర రోగములు,రోగనివారణమునకు అప్పు,ఇతరులను కాపాడుటబోయి శత్రు,రోగాలను కొని తెచ్చుకొనుట
• [BHAVA_LORD_6_7] 6వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : అకాల నిద్ర,భోజనం వల్ల రోగగ్రస్థులు అగుట, భార్య బంధువులు విరోధాలు, భార్యకు అనారోగ్యం, వ్యాపార భాగస్వాములతో విభేదాలు.
• [BHAVA_LORD_6_8] 6వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : అన్యాయాలు, అవినీతి అరికట్టి నాయకుడుగా విజయం పొందుట, శత్రువులకు భయం కలిగించుట, పోటీల్లో నెగ్గుట.
    - హెచ్చరిక : ఆకస్మిక కలహాలు, విరోధాలు, అనారోగ్యాలు, అవినీతిని ఎదుర్కొని ఆపదలను కొని తెచ్చుకొనుట, పోటీల్లో ఓడిపోవుట.
• [BHAVA_LORD_6_9] 6వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : ఋణములు సులభముగా లభించుట,ఇతరులకి ఇప్పించిన అప్పులు సకాలంలో వసూలగుట,ధర్మ కార్యం వల్ల ఋణ రోగం తగ్గించుట
• [BHAVA_LORD_6_10] 6వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : అధికార గౌరవములతో శత్రువులను దెబ్బ తీయుట, ఇతరులను కాపాడుట, వడ్డీ వ్యాపారముతో ధనార్జన.
    - హెచ్చరిక : వృత్తి, ఉద్యోగ, వ్యాపార రంగమందు ఆదాయం తగ్గుటచే, శత్రువులదే పైచేయి అగుట, గౌరవ మర్యాదలకు అప్పుచేయుట.
• [BHAVA_LORD_6_11] 6వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : దురాదాయదుర్లాభముల కొరకు అప్పుచేయుట,అక్కాఅక్కగారివల్ల విరోధములు,విశ్వాసపాత్రులకు అప్పు ఇచ్చి సకాలములో వసూలుకాపోవుట
• [BHAVA_LORD_6_12] 6వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : మోక్ష సాధన కార్యములు ఆచరించి అరిషడ్ వర్గమును జయించుటచే శత్రు పీడ తగ్గుట, పరోపకారముచే ఋణము లభించుట.
    - హెచ్చరిక : దుర్మార్గ సహవాసంచే, ధన దుర్వినియోగం అగుటచే, శత్రు, ఋణ, రోగ బాధలు పొందుట,దుర్వ్యసనముల వాలా ఆరోగ్యం దెబ్బతినుట.

=== 7వ భావం (కల్యాణ/దాంపత్య భావం - వివాహం & వ్యాపారం) ===
• [BHAVA_LORD_7_1] 7వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : శరీర బలముచే,వ్యక్తిగత ఆకర్షణచే భార్య అనుకూలత పొందుట.విందు వినోదములకు ఆహ్వానించబడుట,వ్యాపారభాగస్వాముల అనుకూలత
• [BHAVA_LORD_7_2] 7వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : వాక్ నైపుణ్యంచే, ధనచలామణిచే, సకాల ఆహార, నిద్ర విహారాలవల్ల భార్య ను ఆకర్షించుట, భార్య నుండి విదేయత.
    - హెచ్చరిక : కఠిన వాక్కుచే, దురుసుతనంచే, ధనచలామణి లోటు వల్ల భార్య వ్యతిరేకతలు, భోజన సౌఖ్యం లోపించుట, సుఖ సౌఖ్యాలు లోపించుట.
• [BHAVA_LORD_7_3] 7వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : కనిష్ట సోదర సోదరుల వలన, దాయాదుల వలన భార్యకు కష్ట నష్టాలు, సాంసారిక చిక్కులు, వ్యాపార భాగస్వాములతో పేచీలు, చిక్కులు.
• [BHAVA_LORD_7_4] 7వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : భూ,గృహ,స్థิరాస్తులు భార్య ద్వారా సంప్రాప్తించును, బంధుమిత్ర సేవకుల ద్వారా భార్యకు ప్రయోజనము, వ్యాపార భాగస్వాముల అభిమానం.
    - హెచ్చరిక : భూ,గృహ,వాహన, వస్తులోపం వల్ల భార్య వ్యతిరేకత, భాగస్వాముల వ్యతిరేకత
• [BHAVA_LORD_7_5] 7వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : సమయ స్ఫూర్తి, విద్య, విజ్ఞానం వల్ల భార్యను ఆకర్షించుట, సంతానం ప్రాప్తించును. గ్రామాధిపత్యముచేత భార్య అనుకూలత.
• [BHAVA_LORD_7_6] 7వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రు,ఋణ,రోగములు లేకుండుట ద్వారా భార్య అనుకూలత పొందుట,ఋణము తీసుకున్న వారు విందు భోజనమునకు ఆహ్వానించుట.
    - హెచ్చరిక : శత్రు,ఋణ,రోగముల వల్ల భార్య వ్యతిరేకత, భార్య శత్రు పక్షమును సమర్థించుట, భార్యకు అనారోగ్యము కలుగుట.
• [BHAVA_LORD_7_7] 7వ భావాధిపతి → 7వ భావము నందు స్థితి

    - హెచ్చరిక : భార్య వల్ల, భార్య వర్గం వారి వల్ల ధన నష్టంచే,ఆహార నిద్రా వేళలు తప్పుటచే నిలువ ధనము తగ్గుట. తండ్రి గురువులపై నిందచేయుట.
• [BHAVA_LORD_9_8] 9వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : ఆకస్మిక శుభ సంఘటనలు, శుభకార్యాలు, దైవకార్యాలలో పాల్గొనుట, సాహసకార్యములలో విజయం, అదృష్టంతో తీర్థ యాత్రల దర్శనం.
    - హెచ్చరిక : ఆకస్మిక ప్రమాదముల వల్ల, అపనిందల వల్ల, అపజయముల వల్ల ధన నష్టం, దైవనిందచే దురదృష్టము.
• [BHAVA_LORD_9_9] 9వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : పిత్రార్జితము లభించుట వలన ధననిల్వ పెరుగుట, గురువు, దైవం పెద్దల అనుగ్రహానికి పాత్రులు అగుట, దైవకార్యములతో పుణ్యం పెంచుట.
• [BHAVA_LORD_9_10] 9వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : ఉద్యోగవ్యాపారాదుల వల్ల ధనాదాయంవల్ల నిల్వధనం పెరుగుట, దైవభక్తి గురుభక్తి పెరుగుట.
    - హెచ్చరిక : ఉద్యోగవ్యాపారాదుల వల్ల ఆదాయం తగ్గుట, పెద్దలు గురువుల అనుగ్రహానికి దూరం అగుట, ధనార్జన లోపం వల్ల గౌరవం తగ్గుట.
• [BHAVA_LORD_9_11] 9వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : దురాదాయ,దుర్లాభముల కొరకు, అన్నాఅక్కయ్య వల్ల ధన నష్టం, జూదముల వల్ల ధన నష్టం.
• [BHAVA_LORD_9_12] 9వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : సద్వ్యయముచే ఆదాయము పెరిగి ధనవంతుడు అగుట, పుణ్యాత్ముల సహవాసముచే దైవభక్తి పెరుగుట, మోక్షమార్గ సాధన చేసి,చేయించుట.
    - హెచ్చరిక : ధనము దుర్వినియోగంచే నిల్వధనము తగ్గును,దైవ దూషణము వల్ల నిల్వధనము తగ్గుట, చెడు సాహిత్యముకొరకు ధన వ్యయము చేయుట.

=== 10వ భావం (కర్మ భావం - ఉద్యోగం, వృత్తి, అధికార స్థానం) ===
• [BHAVA_LORD_10_1] 10వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : శారీరక బలముచే వృత్తి,ఉద్యోగ, వ్యాపారములలో అభివృద్ధి, స్వయంకృషిచే ఉన్నత స్థితి పొందుట, అధికారుల యొక్క అండదండలు.
• [BHAVA_LORD_10_2] 10వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : వాక్ నైపుణ్యము వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములలో దినదినాభివృద్ధి పొందుట, ధనచలామణి వల్ల వృత్తి యందు గౌరవము.
    - హెచ్చరిక : మిత వాక్కుచే వృత్తి,ఉద్యోగ, వ్యాపారములో దెబ్బతినుట, ధనచలామణి లోటు వల్ల వ్యాపార ఆదాయం తగ్గుట.
• [BHAVA_LORD_10_3] 10వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : దాయాదులు, కనిష్ట సోదర సోదరీల వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములో ఆటంకములు, గౌరవము తగ్గుట, దగ్గరి ప్రయాణములవల్ల భంగము.
• [BHAVA_LORD_10_4] 10వ భావాధిపతి → 4వ భావము నందు స్థితి
    - శుభం     : భూ,గృహ,వాహన మూలంగా ధనార్జన వల్ల, బంధువుల వల్ల, నూతన సంస్థల స్థాపన వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములో ఆదాయం పెరుగును.
    - హెచ్చరిక : భూ,గృహ,వాహన మూలంగా ధనార్జన వల్ల, బంధువుల వల్ల, నూతన సంస్థల స్థాపన వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములో ఆదాయం పెరుగును.
• [BHAVA_LORD_10_5] 10వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : విద్యావిజ్ఞాన,వివేకం, సమయస్ఫూర్తి వల్ల, గ్రామ ప్రజల అనుకూలత వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములలో దినదినాభివృద్ధి, గౌరవము పెరుగును.
• [BHAVA_LORD_10_6] 10వ భావాధిపతి → 6వ భావము నందు స్థితి
    - శుభం     : శత్రువులు చేసిన పనులచే ముందు జాగ్రత్తగా వృత్తి,ఉద్యోగ,వ్యాపారములలో పటిష్ట పరచుకొనుట, పరోక్షముగా శత్రువుల వల్ల మేలు జరుగును
    - హెచ్చరిక : శత్రువుల వల్ల, అనారోగ్యం వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములో ఆటంకములు ఆదాయం తగ్గుట.
• [BHAVA_LORD_10_7] 10వ భావాధిపతి → 7వ భావము నందు స్థితి
    - హెచ్చరిక : భార్యా మూలకంగా అకాలనిద్ర,భోజన, ప్రయాణాల వల్ల వృత్తి,ఉద్యోగ, వ్యాపారములో దెబ్బతినుట. భాగస్వాముల వల్ల ఆదాయం తగ్గుట.
• [BHAVA_LORD_10_8] 10వ భావాధిపతి → 8వ భావము నందు స్థితి
    - శుభం     : సులభముగా అప్రయత్నముగా ఉద్యోగ ప్రాప్తి, వృత్తి,ఉద్యోగ, వ్యాపారములో ప్రారంభం నుండి గొప్ప గుర్తింపు, దండనాధికారం.
    - హెచ్చరిక : ఆకస్మిక ప్రమాదములు, అవమానములు, అపనిందల వల్ల వృత్తి,ఉద్యోగ,వ్యాపారములు నిర్వహించలేక పోవుట. స్త్రీ మూలక అగౌరవములు.
• [BHAVA_LORD_10_9] 10వ భావాధిపతి → 9వ భావము నందు స్థితి
    - శుభం     : తండ్రి ఆస్తి లభించుట గానీ,దానము చేయుట వల్ల, దైవ కార్యము చేయుట వల్ల వృత్తి,ఉద్యోగ,వ్యాపారములో విశేష అభివృద్ధి,పూర్వ పుణ్యము
• [BHAVA_LORD_10_10] 10వ భావాధిపతి → 10వ భావము నందు స్థితి
    - శుభం     : సులభంగా, తన ప్రతిభ అర్హతలకు ఉద్యోగం లభించుట, వృత్తి,ఉద్యోగ, వ్యాపారములో ప్రజల మన్ననలు, ఉన్నత స్థాయికి ఎదుగుట.
    - హెచ్చరిక : వృత్తి,ఉద్యోగ, వ్యాపారములో ప్రయత్న కార్య భంగముచే ఆదాయము తగ్గుట, అధికారుల ఆగ్రహానికి గురియగుట, పరువు ప్రతిష్ఠలకు భంగము.
• [BHAVA_LORD_10_11] 10వ భావాధిపతి → 11వ భావము నందు స్థితి
    - హెచ్చరిక : దురాదాయ,దుర్లాభముల కొరకు ఆశపడి ఉద్యోగమునకు ముప్పు, ఉపవృత్తి వల్ల, అప్పులు మోసగించడం వల్ల ఉద్యోగంలో సమస్యలు.
• [BHAVA_LORD_10_12] 10వ భావాధిపతి → 12వ భావము నందు స్థితి
    - శుభం     : వృత్తి,ఉద్యోగ, వ్యాపారములో శ్రమించకుండా అభివృద్ధి, సంఘసేవ సంస్థల్లో ఉద్యోగియై పరోపకార సేవ చేయటం వల్ల గౌరవం.
    - హెచ్చరిక : చెడు కార్యముల వల్ల దుర్వ్యయము చేసి పరువు ప్రతిష్ఠలు పోయి ఆదాయం తగ్గుట, ఉద్యోగ ప్రాప్తి కొరకు ఖర్చు ఖర్చు నిష్ఫలమగుట.

=== 11వ భావం (లాభ భావం - ఆదాయం, లాభాలు, ఆశలు) ===
• [BHAVA_LORD_11_1] 11వ భావాధిపతి → 1వ భావము నందు స్థితి
    - శుభం     : వ్యక్తిగత ఆకర్షణ వల్ల, స్వయం కృషిచే, ఆత్మవిశ్వాసంచే సాహస వ్యాపారాలు,షేర్ మార్కెట్లో ఆకస్మికంగా అధిక లాభాలు.
• [BHAVA_LORD_11_2] 11వ భావాధిపతి → 2వ భావము నందు స్థితి
    - శుభం     : కుటుంబంలో వారి ప్రయోజనం వల్ల, వాక్ చతురత వల్ల,వీధిలోని వారి అనుకూలత వల్ల,ధనచలామణి వల్ల ఆకస్మిక ధన లాభముములు ఉండును
    - హెచ్చరిక : కుటుంబంలో వారి వల్ల, వాక్కు వల్ల,వీధిలోని వారి వల్ల,ధనచలామణి లేకపోవడం వల్ల ధన నష్టం.
• [BHAVA_LORD_11_3] 11వ భావాధిపతి → 3వ భావము నందు స్థితి
    - హెచ్చరిక : కనిష్ట సోదర సోదరీలు దాయాదులు, ఇరుగుపొరుగువారి వల్ల, నీచ మార్గ ధనాదాయం వల్ల ఆకస్మిక నష్టములు కలుగును.

    - హెచ్చరిక : భూ,గృహ,వాహనాల వల్ల, బంధుమిత్రులవల్ల, సేవకుల వల్ల ఆకస్మిక ధన నష్టము.
• [BHAVA_LORD_11_5] 11వ భావాధిపతి → 5వ భావము నందు స్థితి
    - శుభం     : మేధాశక్తి, జ్ఞాపక శక్తి వల్ల, సంతానం వల్ల, గ్రామ ప్రజల సహకారం వల్ల, అన్నయ్యలు అక్కయ్యల వల్ల లాభ ముండును.

• జ) జాతకము అనునది జాఫతకము అని ముందే చెప్పాము. ఫతకము అనగా ముందే నిర్ణయించుకొన్నదని అర్థము. జీవిత ఫతకము పుట్టిన సమయములోనే నిర్ణయించడము జరిగినది. అందువలన పుట్టుటను “జా” అన్నారు. అప్పుడు నిర్ణయము చేయబడిన ఫతకమును జాఫతకము అంటున్నాము. జీవితములోని అన్ని సమస్యలు జాఫతకములో ప్రారబ్ధకర్మ ద్వారా నిక్షిప్తము చేయబడియుండును. జాఫతకమును మనము పుట్టిన సమయమును బట్టి వ్రాసుకొన్నా జరిగెడు భవిష్యత్తు ఏమీ అర్థముకాక అంధకారముతో నిండియుండును. అందువలన భవిష్యత్తు అంధకారముతో కూడుకొనియున్నది. ఆ చీకటిలో ఏమీ కనిపించదు. అందువలన ముందు దినముగానీ, ముందు నిమిషముగానీ ఏమి జరుగునదీ తెలియదు. చీకటిమయమైన జాతకమును జ్యోతితో తెలియవచ్చును. జ్ఞానమను జ్యోతిని ఉపయోగించి చూచితే జీవితములోని ఏ సమస్యనైనా తెలియ వచ్చును. జ్ఞానజ్యోతికలవాడు జ్యోతిష్యుడు. అజ్ఞానముగలవాడు సమస్యను గురించి అడుగువాడు. జ్ఞానము తెలియనివాడు ప్రపంచ ప్రశ్నలనే అడుగును. ప్రపంచ ప్రశ్నలకు జవాబునిచ్చు జ్యోతిష్యుడు, తన పరిచయము చేత జ్ఞానము తెలియని వానికి కూడా జ్ఞానము మీద ఆసక్తి కల్గునట్లు ప్రశ్నకు జవాబివ్వవలెను.
• 2) జ్యోతిష్యమునకు భవిష్యత్తుకు తేడా ఏమి గలదు?
• జ) చూచునది దృష్టి, చూడబడునది దృశ్యము. అలాగే తెలియబరచు నది జ్యోతిష్యము, తెలియబడునది భవిష్యత్తు. అట్లే జ్ఞానముతో కూడుకొన్నది జ్యోతిష్యము, భయముతో కూడుకొన్నది భవిష్యత్తు. జ్ఞానముతో కూడుకొన్న వాడు జ్యోతిష్యమును చెప్పును. అజ్ఞానముతో కూడుకొన్నవాడు భవిష్యత్తును అడుగును. భావితరము అంటే రాబోవు తరము అని అర్థము. జ్యోతితరము అంటే వెలుగునిచ్చుతరము. ఇప్పుడు జ్యోతిని ( జ్ఞానమును) వెలిగించితే అది రాబోవు వారికి (తెలియగోరు వారికి) వెలుగై ఉండును.
• 3) జ్యోతిష్యము ఎన్ని రకములు కలదు?
• జ) దేశములో ఎన్ని జ్ఞానములున్నా దేవుని జ్ఞానము ఒక్కటే గలదు. దేవుడు ఒక్కడేగలడు. అదే విధముగా జ్యోతిష్యము అను పేరును ఎన్నో పద్ధతులుగా చెప్పే విధానములకు పెట్టుకొన్నా అవన్నియూ జ్యోతిష్యములు కావు. వాటి వలన భవిష్యత్తు తెలియదు. ద్వాదశ గ్రహముల ద్వారానే కర్మ పాలింపబడుచున్న విధానమునే జ్యోతిష్యము అంటాము.
• 4) ముహూర్తమంటే ఏమిటి?
• జ) ముందే నిర్ణయింపబడినది ముహూర్తము. మధ్యలో మనుషులు నిర్ణయించునది ముహూర్తము కాదు. అన్ని ముహూర్తములు జన్మలోనే ప్రారబ్ధ కర్మతోపాటు నిర్ణయించబడియుండును. మధ్యలో ఎవరూ నిర్ణయించ లేరు. నిర్ణయించినా దానిని ముహూర్తమనరు.
• 5) కొందరు తమ పిల్లలు పుట్టిన సమయములోనున్న నక్షత్రమునుబట్టి పేరు పెట్టుచుందురు. కొందరు ఏమీ చూడకనే పేర్లు పెట్టుచుందురు. అట్లు పెట్టు పేర్లలో బలముండునా? ఎలా పేరు పెట్టడము మంచిది?
• జ) పుట్టిన సమయములో ఉన్న నక్షత్రమునుబట్టి, ఆ నక్షత్రము యొక్క నాలుగు పాదములకు గుర్తుగా నిర్ణయించబడిన నాలుగు అక్షరములలో అప్పటి పాదమునకు సంబంధించిన అక్షరమును మొదటి అక్షరముగా ఉండునట్లు చేసి పేరును పెట్టుకోవడము జరుగుచున్నది. అలా పుట్టిన సమయములోనున్న నక్షత్రమునకు సంబంధిత అక్షరముతో పేరు పెట్టుకొనినా, అలా పెట్టుకొనక వేరే పేరును పెట్టుకొనినా, అందులో లాభముగానీ నష్టముగానీ ఏమీ ఉండదు. కొన్ని పేర్లు పలికే దానికి సులభముగా అందముగా ఉండవచ్చును. కొన్ని పేర్లు కష్టముగా అందహీనముగా మొరటుగాయుండును. అయితే వాటిలో బలముండడము గానీ, ఉండకపోవడముగానీ ఏమీ ఉండదు. ఏ మనిషికీ ఏ పేరువలనా ఎటువంటి బలాబలములుగానీ, లాభనష్టములుగానీ ఉండవు.
• 6) ఒకరి జీవితములో ఒక పెళ్ళిమాత్రము జరుగగా, మరొకరి జీవితములో రెండు పెళ్ళిళ్ళు జరుగుచుండుట చూశాము. దానికి కారణము ఏమి?
• జ) ఒక వ్యక్తి జాతకములో ఏడవస్థానము కళత్ర స్థానమనబడును. కళత్ర స్థానమనగా భర్తకు భార్య కళత్రమగును. అట్లే భార్యకు భర్త కళత్రమగును. కళత్ర స్థానమైన ఏడవ స్థానమున రాహువుగానీ లేక కేతువుగానీ ఉండినట్లయితే ఆ జాతకునికి రెండవ పెళ్ళి జరుగుటకు అవకాశమున్నది. కళత్రము అనగా పురుషునికి స్త్రీ కళత్రమగుననీ, స్త్రీకి పురుషుడు కళత్రమగునని మరొక అర్థము కలదు. అందువలన ఒకవేళ పెలికాకువా పీలకు పురుషులతో పురుషులకు పీలతో అక్రమ సంబందము ఏర్పడునట్లు రాహు కేతు గ్రహములే చేయును. కొందరి కుటుంబములో భర్త చనిపోయిన భార్యవుండినా ఆమె ముండమోసినా విధవగా మిగిలి పోవుచున్నది. అటువంటి ఒక స్త్రీకి ఎటువంటి ఇతర పురుషునితో సంబంధముండదు. అలా ఉండుటకు కారణము ఏమనగా! కళత్ర స్థానములో రాహువు కాని, కేతువు కానీ ఉండినప్పుడు అక్కడే ఆ గ్రహములకు వ్యతిరేకహమైన రెండు లేక మూడు గ్రహములు ఉన్నట్లయితే అక్కడ రాహు కేతువుల ప్రభావము అణిగిపోవును. వారు చేయు రెండవ పెళ్లి కానీ,రెండవ అక్రమ సంబంధముకానీ జరగకుండాపోవును. కళత్ర స్థానములో రాహువు కేంద్రమున్నచోట ఆ గ్రహముకు వ్యతిరేకమైన గ్రహములు కాకుండా అనుకూలమైన గ్రహములుంటే అటువంటి జాతకునికి ఒక పెళ్ళికి బదులు రెండు లేక మూడు పెళ్ళిళ్ళు జరుగునట్లు చేయగలరు. అట్లే ఒక అక్రమ సంబంధమునకు బదులు మరికొన్ని అక్రమ సంబంధములు కలిగింతురు. ఇదంతయు జాతక చక్రములోని గ్రహములు ఆడించు ఆటలే కానీ మనిషి స్వయముగా ఎక్కడా ఆడడము లేదు.
• 7) ఒక వ్యక్తికి పెళ్లి ఆలస్యముగా వయస్సు ముదిరిన తరువాత ఆగుటకు కారణమేమి? అట్లే మరికొందరికి పూర్తి చిన్న వయసులోనే పెళ్లి జరుగుటకు కారణమేమి ఉండవచ్చును?
• జ) మనిషి జీవితములో యవ్వనమునకు అధిపతి కుజగ్రహము. అలాగే కళత్రమునకు అధిపతి శుక్రగ్రహము. ఈ రెండు గ్రహములు వేరువేరు వర్గమునకు చెందినవి. ఒక గ్రహము పాపవర్గము లేక శత్రువర్గము నకు చెందినదైతే మరియొక గ్రహము పుణ్యవర్గము లేక మిత్రవర్గమునకు చెందినదైయున్నది. మనిషి జాతకమునుబట్టి, అందులో జన్మలగ్నమునుబట్టి గ్రహములు రెండు వర్గములుగా విభజింపబడుచున్నవి. ఆ విధముగానున్న గ్రహములలో శనివర్గము వారు పుణ్యమును పాలించువారైయున్నారను కొనుము. అప్పుడు గురువర్గములోని గ్రహములన్నియు పాపమును పాలించునవైయుండును. పుణ్యమును పాలించు గ్రహములను శుభగ్రహము లనీ మిత్ర గ్రహములననీ, అనుకూలమైన గ్రహములననీ అంటుంటాము. అదే పాపమును పాలించు గ్రహములను అశుభ గ్రహములననీ, శత్రుగ్రహములననీ, వ్యతిరేఖమైన గ్రహములననీ అంటుంటాము.
• శనివర్గమునకు చెందిన జాతకునికి జన్మకుండలిలో కళత్ర స్థానమైన ఏడవ స్థానమున శత్రువర్గమునకు సంబంధించిన అశుభగ్రహమైన కుజ గ్రహము ఉన్నాడు. అందువలన కుజగ్రహము యౌవ్వనముకు అధిపతియై నందున జాతకుని యౌవ్వనమును అడవిగాచిన వెన్నెలవలె చేసి, యౌవ్వనములో కళత్ర సుఖము లేకుండా చేయును. అందువలన అటువంటివానికి జీవితములో పెళ్ళియగుటకు ఆలస్యమగును. ఏదో ఒక కారణముచేత పెళ్ళి కుదరకుండా పోవుచు చివరకు వయస్సు ముదిరి పోవును. వయస్సు ముదిరిన తర్వాత పెళ్ళి కావచ్చును. కొందరికి శనివర్గము శత్రువర్గమైనప్పుడు కళత్ర స్థానమున శుక్రుడున్నా లేక శుక్ర హస్తమున్నా కళత్రమునకు అధిపతియైన శుక్రుడు జాతకునికి అశుభమును కల్గించుచూ వానికి యౌవ్వనములో పెళ్ళి అయినా శుక్రగ్రహము వలన యౌవ్వనములో భార్య అనుకూలవతిగా లేకుండును. యౌవ్వనమంతా ఆ జాతకునికి భార్య అనుకూలములేక స్త్రీ సౌఖ్యము లేకుండాపోవును. కుజ గ్రహముగానీ, శుక్ర గ్రహముగానీ శత్రువులుగా ఎవరున్నా వాని యౌవ్వన వయస్సంతయు సుఖము లేకుండా పోవును. కుజ మిత్రవర్గమువాడై శుభగ్రహమై ఏడవ స్థానములోయున్న చిన్నవయస్సులోనే పెళ్ళియగును. శుక్రుడు అశుభ గ్రహమైనా కళత్రమునకు సంబంధము లేకుండా వేరు స్థానములలో ఉండినా అతని కళత్రములో ఆటంకములు లేకుండా సాగి పోవును.
• 8) కొన్ని కుటుంబములలో భార్య భర్త ఇరువురూ ప్రతి చిన్న విషయము నకూ పోట్లాడుకొనుచూ, ఒకరిమాటను మరియొకరు వినకుండ కాపురము చేయుచుందురు. వారు అలా ఉండుటకు కారణమేమి?
• జ) యౌవ్వన కారకుడు కుజుడు, కళత్ర కారకుడు శుక్రుడు అయినందున, వీరు ఇరువురూ శత్రువులగుట వలన చాలామంది జీవితములలో యౌవ్వనములో కళత్ర సుఖముండదు. అంతేకాక పూర్తి శత్రువులుగానున్న వీరు ఇద్దరూ ఒకే లగ్నములో కలిసియున్నప్పుడు జన్మించిన వారికి వారి జీవితాంతము భార్యాభర్తల అన్యోన్యత లేకుండా కాపురము చేయుదురు. కుజగ్రహము ఎవరికి అనుకూలముగాయుంటే వారికి కోపము ఎక్కువయుండును. అందువలన ప్రతి విషయములోనూ కోపగించుకొనుచుందురు. అట్లే కుజ గ్రహము అనుకూలముగాయున్న మగవారికి శుక్రగ్రహము ఇతర స్త్రీల సాంగత్యమేర్పరచును. కుజుడు శుక్రుడూ ఇద్దరూ శత్రువులగుట వలన మనుషుల జీవితములో భార్యాభర్తలు ఏమాత్రము పొందిక లేకుండ జీవితము సాగునట్లు చేయును.
• 9) కొందరు మనుషులు చూచేదానికి అందముగా లేకున్నా బుద్ధి మాత్రము గొప్పగాయుండి వారి ప్రవర్తన గొప్పదిగాయుండును. వారి మేథాశక్తితో ఏ సమస్యకైనా సులభముగా జవాబు చెప్పుచుందురు. కొందరు అందముగాయున్నా తెలివితక్కువవారుగా యుందురు. వారి ప్రవర్తన కూడా తెలివి తక్కువగానే కనిపించుచుండును. అలా ఉండుటకు కారణమేమి?
• జ) కర్మచక్రములోని కర్మ రాశులున్న భాగములలో ఐదవ భాగము లేక ఐదవ స్థానమునందు మనిషి మేథస్సుకు సంబంధించిన కర్మలుండును. అలాగే కాలచక్రములోని పన్నెండు గ్రహములలో బుద్ధికి అధిపతియైనవాడు చంద్రుడు. జాతకచక్రములో చంద్రుడు ఐదవ స్థానములో ఉన్నా చంద్రుని హస్తము అక్కడున్నా అటువంటి వ్యక్తులు మంచిబుద్ధిగలవారై ఉందురు. ఐదవ స్థానము కాకుండ మిగతా పాపస్థానములైన 3,7,11 స్థానములలో ఉండినట్లయితే ఉన్న స్థానమునుబట్టి పూర్తి తెలివితక్కువగా యుండును. చంద్రునితోపాటు శత్రు గ్రహములు కలిసిన అక్కడ కలిసిన గ్రహములనుబట్టి తెలివితక్కువ తనముండును. చంద్రునితోపాటు బుధుడు శత్రువై కలిసియుండడము వలన వ్యాపారములో తెలివితక్కువగా యుండు నని తెలియవచ్చును. అట్లే ఆయా గ్రహములనుబట్టి చెప్పవచ్చును.
• 10) కొందరు కాలము కర్మ అనుచుందురు. మీరు కాలచక్రము, కర్మచక్రము అన్నారు. అవి కనిపిస్తాయా?
• జ) ఏ మనిషికైనా ఏ కర్మయున్నదీ తెలుసుకొనుటకు వీలుపడదు. ఎందుకనగా జాతక చక్రములోనున్న గ్రహములను కాలచక్రములోని లగ్నములందున్నట్లు చెప్పుకొంటున్నాముగానీ, రాశులలోనని చెప్పలేదు. రాశులు కర్మచక్రములో, లగ్నములు కాలచక్రములో ఉంటాయి అని చెప్పుకొన్నాము. రాశియే కనిపించనప్పుడు దానిలోని కర్మ కూడా కనిపించదు కదా! జన్మకుండలిలో వ్రాసుకొను భాగములను జన్మలగ్న కుండలి అంటున్నాము. అంతేగానీ జన్మరాశికుండలి అని అనడములేదు. పంచాంగమును ఉపయోగించి వ్రాసుకొన్న లగ్న కుండలిలో గ్రహములు తెలియుచుండునుగానీ, కర్మ కనిపించడము లేదు. అయినా ప్రతి పనికీ కర్మే కారణమంటున్నాము, గ్రహమే కారణమనడములేదు. కర్మ ఉన్నది గానీ కనిపించడము లేదు. గ్రహములు మాత్రము కనిపిస్తున్నవి గ్రహములు ఉన్నది కాలచక్రములో, అయితే చక్రములోని గ్రహములు కనిపిస్తున్నవిగానీ, కాలము కనిపించడములేదు. కాలము క్రిందనున్న కర్మచక్రము కనిపించుచున్నదిగానీ అందులోని కర్మ కనిపించడము లేదు. క్రిందికి వస్తే గుణచక్రమూ కనిపించడము లేదు. అందులోని గుణములుగానీ, జీవుడుగానీ ఎవరికీ ఏమాత్రము కనిపించడము లేదు. పైనగల కాల చక్రములో చక్రమూ, చక్రములోని గ్రహములూ కనిపించగా, కాలము కనిపించడములేదు. క్రిందయున్న కర్మచక్రములో చక్రము మాత్రము కనిపించుచున్నదిగానీ, చక్రములోని కర్మ కనిపించడము లేదు. ఇక ఇంకా క్రిందికిపోతే గుణచక్రమున్నది. అయితే అక్కడ చక్రమూ కనిపించడము లేదు. అందులోని గుణములూ కనిపించడములేదు. గుణములలోనున్న జీవుడూ కనిపించడము లేదు. మనము బాగా మనోదృష్టి పెట్టి ఆలోచించాలి. పైనగల కాలచక్రములో చక్రమూ గ్రహములు రెండూ కనిపించగా, దాని క్రిందగల కర్మచక్రములో చక్రము మాత్రము కనిపించగా, దానికంటే క్రింద గుణచక్రము, గుణములు, జీవుడులో ఏ ఒక్కటీ కనిపించలేదు. దీనినిబట్టి పైకి పోయే కొద్దీ దృష్టి పెరుగుతుందనీ, క్రిందికి వచ్చేకొద్దీ దృష్టి తరుగుతుందనీ అర్థమగుచున్నది. మీకు అర్థమైనా అర్థముకాకున్నా మేము చెప్పునదే మనగా, కాలమూ కనిపించదు, కర్మమూ కనిపించదు. కాలము కర్మ ఎవరి కోసమున్నాయో ఆ జీవుడూ అక్కడే యున్న గుణములూ ఏమాత్రము కనిపించవు. ప్రపంచములో ఏ మనిషీ ఈ మూడునూ చూడలేడు. అయితే ఇప్పుడు కొందరు తెలివిగా నన్ను ఒక ప్రశ్నను అడుగవచ్చును. అదేమనగా! “మీరు వ్రాసిన గ్రంథములలో ఇది కాలచక్రమని, దానిక్రింద ఇది కర్మ చక్రమనీ, దానిక్రింద గుణచక్రమని బొమ్మవేసి చూపి అందులో జీవుడిట్లున్నా డనీ, గుణములు ఇట్లున్నవనీ బొమ్మతో సహా చూపారు. ఏ మనిషీ చూడలేదని చెప్పిన మీరే ఆ బొమ్మలను చూపారు కదా! గుణచక్రము అందులోని మూడు భాగములు ఎట్లుండునో తెలియని మాకు గుణభాగము లనూ జీవుని ఆకారమునూ చూపారు కదా!” అని అడుగవచ్చును. దానికి మా జవాబు ఇలాయున్నది చూడండి. ప్రపంచములో ఏ మనిషీ చూడలేదు అనేమాట బ్రహ్మవిద్యా శాస్త్రములోని శాసనము. ఆ శాసనము ఎప్పటికీ మారదు, అసత్యమూ కాదు. అయితే మీరెలా చెప్పారు? అని మీరు అడిగినది హేతుబద్ధమే అయినా దానికి నేను కూడా హేతుబద్ధముగానే సమాధానము ఇస్తున్నాను. అక్కడ వాక్యములో ఏ మనిషీ చూడలేదు అన్నమాటను చూచిన తర్వాత మీకు మరొక జ్ఞప్తి కూడా రావలసింది. జనన మరణ సిద్ధాంతమును చెప్పినప్పుడు ఈ విషయము ప్రపంచములో పుట్టినవానికి ఎవనికీ తెలియదని చెప్పినప్పుడు ఇప్పుడు అడిగిన ప్రశ్న అప్పుడే అడుగవలసింది. అయినా ఫరవాలేదు. ఇప్పుడు అడిగారు కాబట్టి సంతోషిద్దాము. జనన మరణ సిద్ధాంతములోని విషయముగానీ, ఇప్పుడు చెప్పిన కాలము, కర్మము చెప్పిన విషయముగానీ ఏ మనిషికీ తెలియదు అని చెప్పినప్పుడు ఇది ఒక మనిషి చెప్పిన విషయమని మీరెలా అనుకుంటు న్నారు? మీకు కనిపించేది మనిషే అయినా నేను చెప్పినట్లు అనుకోవడము పొరపాటు. నేను ఎన్నోమార్లు చెప్పాను. ఇప్పుడు కూడా గుర్తు చేయుచున్నాను. నాకు ఏమీ తెలియదు. అందువలన ఎవరికీ తెలియదని చెప్పిన దేవునిమాట వాస్తవము. ఏ రహస్యమైనా మన శరీరములోనున్న ఆత్మకే తెలుసు.
• ఆత్మ అందరినీ నడిపించుచూ ఇటు జీవునిగా అటు దేవునిగా భ్రమింపజేయుచూ, తాను మాత్రము ఎవరికీ తెలియక నిశ్శబ్ధముగా యున్నది. అన్నిటికీ అధిపతియైన దేవుడు తనకు మనకు మధ్యలో ఆత్మనుంచి సాక్షిగా వినోదమును చూస్తున్నాడు. ఎలాగైతేనేమి, అన్నీ తెలుసుననుకొన్న జీవునికీ ఏమీ తెలియదని నిజంగా ఏ జీవునికీ తెలియదు. అందువలన కాలము ఎవరికీ తెలియదు. అట్లే కర్మ కనిపించడము లేదు. జీవుడు, గుణములను స్వయముగా ఎవరూ చూడలేదు. మేము చూపితే మీరు చూడగలిగారు, మేము చెప్పితే వినగలిగారు. అంతేగాని దేవుని మాట ప్రకారము మేము తప్ప ఎవరూ స్వయముగా చూడలేదని చెప్ప వచ్చును.
• 11) మాకు జ్యోతిష్యము తెలియాలంటే ఈ గ్రంథము చదివితే అర్థమవుతుందా?
• జ) సహజముగా ఎవరి గ్రంథమును వారు గొప్పగా చెప్పుకొందురు. అందువలన ఈ గ్రంథము చదివితే బాగా అర్థమవుతుందని నేను చెప్పినా, అది అర్థమగుటకూ, అర్థము కాకుండుటకూ ఒక విధానమును అనుసరించి చూస్తే ద్వాదశ గ్రహములలో ఒక బుధగ్రహము అనుకూలము లేనప్పుడు జ్యోతిష్యము అర్థముకాదు. బుధగ్రహము జన్మ లగ్నమున అనుకూలమైన మిత్ర గ్రహమై ఐదవ స్థానములో ఉన్నా, తన చేతితో తాకినా, అటువంటి జాతకునికి జ్యోతిష్యము మీద ఆసక్తి కల్గి దానిని తెలియునట్లు చేయును. ఆసక్తి పెరుగుకొద్దీ   అర్థమగుచూవచ్చును. ఏదీ ఒక్కమారు రాదు కాలక్రమేపీ రాగలదు.
• 12) గతములో చాలామంది జ్యోతిష్యశాస్త్ర రచయితలు వారివారి గ్రంథములైన జ్యోతిష్య ఫలగ్రంథము, యవన జాతకము, జాతక మార్తాండము, జాతక చంద్రిక మొదలగు పుస్తకములందు సూర్యుడు, కుజుడు, శని, రాహువు, కేతువులను కూరులనీ, బుధ, గురు, శుక్ర, చంద్రులను సౌమ్యులనీ చెప్పారు. ఇంకనూ చాలా పుస్తకములలో ఈమాటే ఉన్నది. వేరు జ్యోతిష్యులందరూ ఈ విషయమునే చెప్పుచున్నారు. అది ఎంతవరకు వాస్తవము?
• జ) అది ఏమాత్రమూ వాస్తవము కాదని చెప్పుచున్నాము. మంచి పనిని చేయువారిని శుభులనీ, చెడు పనిని చేయువారిని అశుభులనీ అనవచ్చును. కాలచక్రములోని గ్రహములు కొన్ని పుణ్యమును పాలించునవిగ, కొన్ని పాపమును పాలించునవిగ ఉన్నమాట వాస్తవమే.
• పాపమును పరిపాలించువారిని కూరులు, పాపులు, అశుభులు, శత్రువులు అని పిలువవచ్చును. అలాగే పుణ్యమును పాలించువారిని సౌమ్యులు, పుణ్యులు, శుభులు, మిత్రులు అని పిలువవచ్చును. గ్రహములు రెండు గుంపులుగా ఉండడము వాస్తవమే అయినప్పటికీ, ఒక లగ్న జాతకునకు పాపమును పాలించుచు కూరులుగా ఉండినవారే మరొక లగ్న జాతకునకు పుణ్యమును పాలించువారై సౌమ్యులుగా ఉన్నారు. జాఫతక లగ్నములను బట్టి కొందరికి శాశ్వితముగా కూరులుగానున్న గ్రహములు, మరొక జాఫతక లగ్నమును బట్టి మరికొందరికి శాశ్వితముగా సౌమ్యులుగా ఉన్నారు. అందువలన అందరికీ శాశ్వితముగా . కూరగ్రహములు లేవు, అట్లే సౌమ్య గ్రహములు లేవు. అలా అందరికీ శాశ్వితముగా కొన్ని గ్రహములు కూరులుగా ఉన్నారని అంటే, అది శాస్త్రబద్దత లేకుండా ఇష్టమొచ్చినట్లు చెప్పినదగును. జ్యోతిష్యము షట్ శాస్త్రములలో ఒక శాస్త్రము కావున సూత్రబద్దత కల్గియున్నది. 2:1 అను సూత్రము ప్రకారము, మిత్రులు శత్రువులు అను రెండు వర్గములను విభజించాము. దాని ప్రకారము ఒకనికి మిత్రులైన గ్రహములు మరొకనికి శత్రువులు కావచ్చును. ఆరు లగ్నములకు శత్రువులై, కౄరులుగా వర్తించు గ్రహములు, మరొక ఆరు లగ్నములకు మిత్రులై, సౌమ్యులుగా వర్తించుచున్నారు. ఒక శాస్త్రమును అనుసరించి, అందులోనూ ఒక సూత్రమును అనుసరించి ఎవరు ఎవరికి సౌమ్యులో, ఎవరు ఎవరికి కూరులో మేము వివరించి చెప్పాము. అట్లుకాక ఏ లగ్నమునూ ఆధారము చేసుకొని చూడక, ఏ సూత్రమునూ అనుసరించకుండ రవి, శని, కుజ, రాహు, కేతువులను కూరులనడము, గురు, బుధ, శుక్ర, చంద్రులను సౌమ్యులు అనడము పూర్తి శాస్త్ర విరుద్ధమని చెప్పుచున్నాము. సంస్కృతములో ఇష్టమొచ్చినట్లు శ్లోకములను అల్లి చెప్పినంతమాత్రమున అందులో శాస్త్రీయత లేకపోతే అది వాస్తవము కాదు. ఇక్కడొక ఉదాహరణను చూస్తాము.
• శ్లోకం, దుఃఖావహా ధనవిశాకరాః ప్రతిష్టా విత్తస్థితా రవిశనైశ్చర భూమిపుత్రాః చంద్రోబుద్ధస్సుర గురుర్బృగునందనోవా, సర్వేధనస్య నిచయల కురుదే ధనస్థాః
• తాత్పర్యము : ద్వితీయ స్థానములో రవి,శని, కుజులలో ఎవరున్ననూ ధననాశనమును, అధిక దుఃఖమును కల్గించి బాధింతురు. చంద్ర,బుధ, శుక్రులలో ఏ ఒక్కరున్ననూ ధనలాభమును కలిగింతురు.
• ఈ శ్లోకమూ దాని తాత్పర్యమూ “యవన జాతకము" అను పుస్తకములో వ్రాయబడియున్నది. ఇందులో మేము అడుగునదేమనగా! ద్వితీయమున చెడు గ్రహములుంటే, ధన నాశనము దుఃఖము కల్గుననుట ఒప్పుకుంటాను. కానీ ఏ లగ్నము ద్వితీయమున వీరు చెప్పిన గ్రహములు ఉన్నారో చెప్పకపోవడము, మరియు రవి, శని, కుజులు, ఏ లగ్నమునకు కూరులో, ఎట్లు కూరులైనారో చెప్పకపోవడము పూర్తి అశాస్త్రీయత అని చెప్పవచ్చును. మేము 2 :1 అను ఆత్మల సూత్రమును అనుసరించి గ్రహములను రెండు గుంపులుగా చేశాము. వాటినే గురువర్గము, శని వర్గము అని కూడా చెప్పాము. శని, బుధ, శుక్ర, రాహువులను ఒక గుంపులో; సూర్య, చంద్ర, కుజ, గురు, కేతులను ఒక గుంపులో ఉన్నాయని మేము చెప్పితే జ్యోతి తెలియనివారు రెండు గుంపులలోని వారిని కలుపుకొని సూర్య, కుజ, శని, రాహు,కేతులను కూరులన్నారు. ఇందులో మా లెక్కప్రకారము సూర్య, కుజ, కేతువులు గురువర్గములోనివారు కాగా, ఈ ముగ్గురిలో ప్రతిపక్ష గుంపులోని రాహువు,శని కలిసిపోవడము పూర్తి తప్పు. అంతేకాక 1x7 అను సూత్రము ప్రకారము సూర్యునకు బద్ద శత్రువు శని అగును. అలాగే శనికి బద్ధశత్రువు సూర్యుడగును. అటువంటివారు ఒక గుంపులో కూరులుగా ఉన్నారని చెప్పడము అసంబద్దము, అశాస్త్రీయము. అందువలన సంస్కృత శ్లోకములోనున్న తప్పుడు సమాచారమును నమ్మ వద్దండి. ఇటువంటి అశాస్త్రీయత జ్యోతిష్యములో కనిపిస్తున్నది. కావున నేటి హేతువాదులు, నాస్తికవాదులు జ్యోతిష్యము శాస్త్రము కాదంటున్నారు. టీవీ9 వారు జ్యోతిష్యము మూడనమ్మకము అంటున్నారు. అందువలన మేము పూర్తి శాస్త్రీయతతో ఈ గ్రంథమును వ్రాసి,  షట్ శాస్త్రములలో ఐదవశాస్త్రమని చెప్పుచున్నాము.
• 13) ఇంతవరకు చెప్పిన అతిరథులు, మహారథులు గ్రహములు తొమ్మిదే అని చెప్పగా, ఎవరూ చెప్పని మూడు గ్రహములను మీరు చెప్పారు. మీరు ఎక్కడా ఎవరికీ జ్యోతిష్యము చెప్పినది కూడా లేదు. భవిష్యత్తు (జ్యోతిష్యము) చెప్పు అనుభవముగానీ, అలవాటుగానీ లేని మీరు ఏకంగా ద్వాదశ గ్రహములను ప్రకటించి, జ్యోతిష్య గ్రంథమును శాస్త్రబద్దముగా, సూత్ర యుక్తముగా వ్రాస్తున్నామంటున్నారు. ఇది సంభవమగునా?
• జవాబు. ఇంతవరకు చెప్పినవారు రథులో, అతిరథులో, మహారథులో, వీరులో, శూరులో నాకు తెలియదు. జ్యోతిష్యములో నేను మాత్రము . కేవలము రథుడను కూడా కాను. అటువంటపుడు నీవు వ్రాయునది సక్రమమేనా? అని నన్ను అడుగుటలో మీ తప్పేమీలేదు. మీ ప్రశ్నకు మేము చెప్పు సమాధాన మేమనగా! నాకు జ్యోతిష్యము తెలియదు కానీ, నా శరీరములో నా ప్రక్కనేయున్న వానికి, షట్ శాస్త్రములు సంపూర్ణముగా తెలియును. ఇక్కడ ఒక సూత్రమును ఉదహరించితే ఒక ఇనుప ముక్క ప్రక్కలో అయస్కాంతము ఉండినా, ఒకవేళ అయస్కాంతము ప్రక్కలో ఇనుపముక్క ఉండినా ఇనుప ముక్కే అయస్కాంతముగా మారుతుంది, కానీ అయస్కాంతము ఇనుప ముక్కగా మారదు. అలాగే ఒక తెలియని వాని ప్రక్కలో తెలిసినవాడుండినా, ఒకవేళ తెలిసినవాని ప్రక్కలో తెలియని వాడుండినా, తెలియనివాడే తెలిసినవాడుగా మారును. కానీ తెలిసినవాడు తెలియనివానిగా మారడు. ఈ సూత్రము ప్రకారము, నేను జ్యోతిష్యము తెలియనివాడినే, కానీ జ్యోతిష్యము తెలిసినవాని ప్రక్కన ఉన్నాను. కనుక అసలైన జ్యోతిష్యమేమిటో నాకు తెలిసింది. ఇద్దరము కలిసి మీకు చెప్పగలుగుచున్నాము. ఈ సూత్రము ప్రకారమే సైన్సు అభివృద్ధిని పురాతన కాలములోనే, పాశ్చాత్యులు గుడ్డలు కూడ కట్టని అనాగరిక కాలములోనే, ఖగోళ పరిశోధనలు లేని కాలములోనే, ఏ వ్యోమనౌకలు ఆకాశములోనికి పోని కాలములోనే, కొందరు మహర్షులు తొమ్మిది గ్రహములనూ, వాటి వేగమునూ, గ్రహణములనూ పసిగట్టి చెప్పగలిగారు. తమ ప్రక్కవానిని గుర్తించినవారు ప్రక్కవాడు చెప్పినట్లే చెప్పారు. ఈనాడు ఎంతో వ్యయప్రయాసలతో ఆకాశములోనికి ఉపగ్రహమను రాకెట్ పంపి, కుజగ్రహము ఎర్రగ ఉన్నదని, ఇప్పుడిప్పుడు ఖగోళ శాస్త్రజ్ఞులు చెప్పు చున్నారు. కుజగ్రహము ఎర్రగ ఉన్నదని కొన్ని లక్షల సంవత్సరముల పూర్వమే మన మహర్షులు చెప్పారు. ఏ శాస్త్రమూ అభివృద్ధికాని కాలములోనే, వారు చంద్రుడు తెల్లని చౌడు భూమియని కూడా చెప్పారు. వారు ఆ రోజులలో వారి ప్రక్క వానిని గుర్తించి, వాడు చెప్పినట్లు చెప్పారు తప్ప, వారు చంద్రుని మీదికి, కుజుని మీదికి పోయి చూడలేదు. అలాగే వారు చెప్పిన పద్ధతి ఏదో, దాని ప్రకారము నా శరీరములో, నా ప్రక్కనే యున్న వాని సహకారముతోనే, నేడు నేను గ్రహములు తొమ్మిది కాదు మొత్తము పండ్రెండని చెప్పుచున్నాను. అర్థమైందా, ఇంకా ఏమైనా అనుమానముందా? ప్రక్కవాడు మీలో కూడా ఉన్నాడు, కానీ మీలో మీరు తప్ప ఎవరూలేరను గ్రుడ్డితనములో ఉన్నారు. కావున ప్రక్కవానిని విస్మరించిపోయారు. వానిని తెలియాలంటే 'జ్ఞానాంజనము' అను కాటుక కావాలి. కాటుకతోనే గ్రుడ్డితనము పోయి అతడు కనిపిస్తాడు. జ్ఞానాంజనము కావాలంటే ఎటు తిరిగీ షట్ శాస్త్రములలో చివరి ఆరవ శాస్త్రమైన బ్రహ్మవిద్యాశాస్త్రమును తెలిసి తీరాలి. అదెక్కడుండేది మాకు తెలియదే అనుకోవద్దండి. అదియే భగవద్గీత. సూటిగా చెప్పాలంటే అదే "త్రైత సిద్ధాంత భగవద్గీత”. దానిని చదివితే మీలోనే మీ ప్రక్కనేయున్న వాడు తెలియును. వానిని తెలుసుకొంటే వాని ద్వారా ఏ రహస్యమైనా తెలుసుకోవచ్చును.
• 14) ఒక వ్యక్తి వ్యవసాయము కొరకు బావి త్రవ్వితే నీరు రాలేదు. బోరువేస్తే నీళ్ళు పడినాయికానీ బోరు పూడిపోతున్నది. దానివలన నీళ్ళు రాలేదు. రెండుచోట్ల బోరువేసినా అట్లే అయినది. అతనికి నీరు అనుకూలము లేదా?
• జ) నీరుగానీ, నిప్పుకానీ, ప్రపంచములో ఏ వస్తువుగానీ, అన్నియూ గ్రహముల ఆధీనములో ఉండును. ఎవరికీ నీళ్ళు అనుకూలము అనాను . కూలము లేదు అనుట సరియైనది కాదు. ఎందుకనగా నీరు చంద్రగ్రహము యొక్క ఆధీనములో ఉండును. చంద్రగ్రహము అనుకూలము ఉంటే నీళ్ళు అనుకూలమగును. చంద్రుడు అనుకూలము లేకపోతే నీరు అనుకూలము ఉండదు. ఏ వస్తువుకైనా ఆ వస్తువు యొక్క అధిపతి గ్రహము ఎవరో ఆ గ్రహము అనుకూలము అనానుకూలము మీద ఆధారపడి ఆ వస్తువు లభించేది, లభించనిది తెలియును. లభించినా మంచిది లభిస్తుందా లేదా అను విషయము కూడా ఆ గ్రహమునుబట్టి మరియు ఆ గ్రహముతో కలిసిన మిగతా గ్రహములనుబట్టి, ఆ వస్తువున్న రాశి స్థానమునుబట్టి వస్తువు లభ్యమగునా లేదాయని లభ్యమైనా ఎటువంటిది లభ్యమగునని తెలియ గలదు. చంద్రుడు అనుకూలమున్నట్లయితే బావిని త్రవ్వినా, బోర్లు వేసినా నీళ్ళు సులభముగా లభ్యమగును. ఒకవేళ చంద్రుడు శత్రు గ్రహమైతే నీళ్ళు పడవు. చంద్రుడు శత్రుగ్రహమై నాల్గవ స్థానమును తాకినప్పుడు లేక నాల్గవ స్థానములోనేయున్నప్పుడు అతని నివాసగృహములో కూడా నీళ్ళు అనుకూలముగా ఉండవు. వర్షము వస్తే ఏదో ఒక విధముగా నీరు ఇంటిలోనికి వస్తుంది. ఎంతమంచి ఇల్లయినా చంద్రుడు సరిగా లేకపోతే ఆ ఇల్లు నీరుకారే ఇల్లుగా ఉండును. అదంతయు బాగుంది. అంటే బాత్ రూమ్ లో నీళ్ళు రాకుండాపోవడమో లేక మురికినీరు బయటికి పోకుండా ఉండడమో జరుగును. ఒకదానిని సరిచేస్తే నీటిని గురించిన క్రొత్త సమస్యలు వస్తూనే ఉండును. మంచినీరులో ఉప్పునీరు మిశ్రమమై కూడా వచ్చును. అట్లే బోరు నీళ్ళలోనికి మురికినీరు చేరి అదే నీరు రావచ్చును. ఇట్లు అనేక నీటి సమస్యలు రాగలవు.
• 15) కొంతమంది తమ పొలము దగ్గర దారి సరిగా లేక ఇబ్బంది పడుచుందురు. అట్లే కొంతమంది తమ ఇంటివద్ద దారిలేక ఇబ్బంది పడుచుందురు. అదెందుకు జరుగుచుండును?
• జ) ప్రపంచములో ప్రతి దానికీ గ్రహములే అధిపతులు. అట్లని గ్రహములను దేవుళ్ళని అనుకోకూడదు. ప్రభుత్వము నుండి కరువు సహాయము అందినప్పుడు మొదట ఆ డబ్బు జిల్లా కలెక్టర్ వద్దకు వచ్చి, కలెక్టర్ నుండి మండల ఆఫీసర్ వద్దకు వచ్చి చివరకు బ్యాంకు క్యాషియర్ ద్వారా నీకు వచ్చినదనుకొనుము. ప్రతి సహాయము ఎక్కడినుండి డబ్బు వచ్చినా బ్యాంకు క్యాషియర్ నుండే తీసుకోవలసియున్నది. అట్లని క్యాషియర్ నే ప్రభుత్వము అనుకోకూడదు. అలాగే గ్రహములు ఉన్న కర్మను ఇచ్చు క్యాషియర్లాంటివి. మనిషికి సృష్ఠినుండి ఏది లభించినా గ్రహముల ద్వారానే లభించాలి. గ్రహములన్నియూ ప్రకృతి ఆధీనములో ఉండగా, ప్రకృతి పరమాత్మ ఆధీనములో ఉన్నది. చివరికి అన్నిటికీ పెద్ద దేవుడే. ఇప్పుడు అసలు విషయానికి వస్తే భూమిమీద దారులన్నీ కుజగ్రహము ఆధీనములో ఉండును. జాతకములో కుజగ్రహము వ్యతిరేఖియై నాల్గవ స్థానములోయున్నా, నాల్గవ స్థానమును తన చేతితో తాకినా, పొలములు గృహముల దారులలో ఆటంకములు ఏర్పడును. తరచూ త్రోవలకు సంబంధించిన పేచీలు వచ్చుచుండును. కుజుడు దక్షిణ దిశకు అధిపతి యైనందున దక్షిణ దిశకున్న దారులలోనే ఎక్కువ పేచీలు వచ్చును. దారులేకాక ఇళ్ళు కూడా దక్షిణమువైపు కృంగుటయో లేక దక్షిణవైపు గోడలు చీలుటయో జరుగుచుండును. ఇటువంటి కుజ దోషములకు ఏ గృహశాంతులుగానీ, అష్టదిగ్భంధన యంత్రములుగానీ, ఏ విధమైన ఉపశమన మార్గములూ పనికిరావు.
• 16) కొందరు ఎంత సంపాదించినా చివరకు డబ్బులతో ఇబ్బంది పడుచుందురు. ఎప్పుడూ అప్పులలో కూరుకుపోయివుందురు. అదెందుకు జరుగుచున్నది?
• జ) “ ధనమూల మిదమ్ జగత్” అని కొందరనుచుందురు. ప్రతి దానికీ ధనమే మూలమైనదిగా కనిపించుచుండినా, ధనమునకు మూలము శుక్రగ్రహము మరియు గురుగ్రహమని చెప్పవచ్చును. గురుగ్రహము డబ్బును నిలువజేసి ధనికులను చేయును. శుక్రగ్రహమైతే డబ్బును నిలువ చేయక ప్రవాహములాగ కదలించుచూ డబ్బు ద్వారా అన్ని సుఖములను అనుభవింపజేయును. అందువలన కదలే డబ్బుకు శుక్రగ్రహము, కదలని డబ్బుకు గురుగ్రహము అధిపతులుగాయున్నారు. ఈ రెండు గ్రహములు వారి జాతకములో వ్యతిరేఖ స్థానములలో ఉండినా, వ్యతిరేఖ గ్రహములతో కలిసినా డబ్బు వస్తున్నా అది తమవద్ద నిలువక అవసరములకు తక్కువ వస్తూ ఇబ్బంది పడవలసివచ్చుచుండును. గురు, శుక్రులు జాతకునకు అనుకూలముగాయుండిన, అంటువంటివారు డబ్బుతో ఏ ఇబ్బందులూ పడకుండా బ్రతుకుచుందురు.
• 17) కొందరు పేదవారైనా వారికి స్వంత ఇల్లు ఉండును. కొందరు ధనికులైనావారికి స్వంత ఇల్లు ఉండదు. దానికి కారణమేమి ఉండవచ్చును.
• జవాబు. స్వంత ఇల్లుగానీ, స్వంత భూములుగానీ అన్నియు స్థిరాస్తులు అనబడును. స్థిరాస్తులకు స్థానము జన్మకుండలిలో నాల్గవ స్థానము. అక్కడ ఒక శుభగ్రహమున్నట్లయితే అతనికి స్వంత ఇల్లు మొదలగు స్థిరాస్తులు కల్గును. అక్కడ అశుభగ్రహముండినట్లయితే స్వంత స్థిరాస్తులు ఏమీ ఉండవు. జాతకములో నాల్గవ స్థానములో ఒక మంచి గ్రహమున్నా లేక తాకినా అతనికి స్వంత గృహముండును. అట్లు గ్రహచారము మంచిగా లేని వానికి స్వగృహముండదు.
• 18) మీరు మూడు కొత్త గ్రహములను గురించి చెప్పారు. వాటి ప్రభావము అందరిమీదా ఉంటుందా? లేక కొందరిమీదనే ఉంటుందా?
• జ) అందరిమీదా సమానముగా వాటి ప్రభావముంటుంది. కొందరి మీద వాటి ప్రభావముండి కొందరి మీద ఉండదనుటకు అవకాశమేలేదు. ఇంతవరకు ఏ గ్రహమూ అట్లు ఉండలేదు. అన్ని గ్రహములు అందరికీ సమానముగా ఉన్నాయి.
• 19) క్రొత్త గ్రహములను అందరూ ఒప్పుకుంటారా? మీ మాట సత్యమని నమ్ముతారా?
• జవాబు. ఒప్పుకోవడమూ, ఒప్పుకోక పోవడమూ నాకు సంబంధములేదు. నా మాట సత్యమని కూడా నేను చెప్పను. దేవుడు చెప్పిన జ్ఞానాన్నే కొందరు ఒప్పుకొంటున్నారు. కొందరు ఒప్పుకోవడములేదు. అటు వంటపుడు దేవుని జ్ఞానాన్నే ఒప్పుకోని వారున్నప్పుడు, నా జ్ఞానాన్నిగానీ, నా సూత్రములనుగానీ ఒప్పుకోమని నేను చెప్పడము లేదు. తెలుసుకోండి యని, ఆలోచించండని మాత్రమే చెప్పుచున్నాము.

• 21) మేము చివరిగా అడిగిన మాటకు మీరు చెప్పగలరా అనుమాటకే జవాబు చెప్పండి?
• జ) మీరు చేపలు అమ్మే వాని వద్దకు పోయి “నీవు నాకు కావలసిన చేపను అమ్మగలవా” అని అడిగినట్లున్నది. చేపల వానిదగ్గర అన్ని రకముల చేపలూ ఉంటాయి. ముందు నీకు కావలసిన చేప ఏదో అడిగితే బహుశా ఉంటే ఇస్తాము, లేకపోతే లేదు అని చెప్పుతారు. అట్లు కాకుండా ముందే నాకు కావలసిన చేప అంటే తిరిగి నేను ఏ చేప అని అడగడము తర్వాత నీవు చెప్పడము దానికి బదులుగా అప్పుడు నేను చెప్పడము జరుగవలెను. అంత రాద్ధాంతము లేకుండా నీకు కావలసిన సిద్ధాంత చేప ఏదో చెప్పితే నావద్ద ఉత్త చేపలున్నాయో, సిద్ధాంత చేపలున్నాయో నాకు కూడా తెలిసి పోతుంది కదా! ఇప్పుడు మీరు అడిగిన ప్రశ్న సూత్రబద్ధమైనది. దానికి నావద్దయున్నవన్నీ సిద్ధాంతబద్దమైనవి, సూత్రబద్దమైనవి కావున మేము సులభముగా చెప్పగలము. అదే ప్రశ్ననే మరియొకమారు చిన్నచిన్న ప్రశ్నలుగా అడుగు.
• 22) ఒకే సమయములో, ఒకే విధ కర్మలేనివారికి, వేరువేరు కర్మలున్న వారికి ఒకే ప్రమాదము జరుగగలదా?

దేవున్ని పూజించేవారూ నేడు దైవజ్ఞాన దూషణ చేస్తూ అటువంటి పనిని మేము చేస్తామా? మేము చేసినదంతా మంచిదే అని అనుకొంటున్నారు. అయినా అటువంటివారు ఇప్పటికే చాలామంది వారు దైవజ్ఞానమునకు వ్యతిరేఖులైయున్నారు. అటువంటి వారందరికీ ఎప్పుడో ఒకమారు చెప్పకనే జరిగిన బస్సు ప్రమాదములాగ ఏదో ఒక ప్రమాదము జరుగును. అప్పుడు వారందరూ అక్కడ జమకూడుదురని మాకు తెలుసు, దేవునికి తెలుసు ఎవరు ఏమి తప్పు చేసినది. అందువలన ఎవరినీ దేవుడు కాపాడలేదు. తనకే వ్యతిరేఖులైన వారిని ఆయన ఎందుకు కాపాడును? ప్రస్తుత కాలములో దేవుడు భగవంతునిగా వచ్చి చెప్పిన భగవద్గీతను కాలితో తన్ని నడిరోడ్డులో అగ్గిపెట్టి కాల్చినవారు దైవభక్తి కలవారే. మేము సృష్టికర్త కోడ్ యని భగవద్గీతలో 15వ అధ్యాయమున 16, 17 శ్లోకముల నంబర్లను కూడా వ్రాసి “9 6 3” అని గోడలమీద వ్రాస్తే ఇది క్రైస్తవులదని దానిమీద మలము చల్లినవారుగలరు. మేము (మా భక్తుల బృందము) భగవద్గీతనూ దానికి అనుబంధమైన గ్రంథములనూ ఇల్లిల్లూ తిరిగి భగవద్గీతా ప్రచారము చేస్తే క్రైస్తవులు తప్ప హిందువులు ఇట్లా తిరుగరు మీరు భగవద్గీత ముసుగులో క్రైస్తవమును ప్రచారము చేస్తున్నారని దూషించి ఆ ఊరినుండి పొమ్మని, పోకపోతే మీ బుక్కులను కాల్చివేస్తాము, మిమ్ములను తంతామనినవారు కూడా కలరు. త్రైత సిద్ధాంత భగవద్గీతను చదవండియని మేము ఎంతో ఖర్చు పెట్టి గోడలమీద వ్రాయిస్తే దాని కారణముతో కేసు పెట్టి కోర్టుకీడ్చి 20 రోజులు జైలుశిక్ష వేయించిన వారున్నారు. ఆ దినము కోర్టులో ఇది తప్పా ఒప్పాయని చూడకుండా, ఏమాత్రము ఆలోచించకుండా తీర్పు చెప్పి జైలుకు పంపిన జడ్జిని కూడా జ్ఞానము గుర్తుపెట్టుకొనియున్నది. ముందు తరములో జ్ఞానదూషణ చేసిన వారందరూ బస్సులో కాలిపోవడము జరిగినది. ఈ తరములో జ్ఞానదూషణ చేసినవారు మహానంది, గుంతకల్లు, హైదరాబాద్, భువనగిరి, కడపలో దేవుని దృష్టియందు నమోదు చేయబడియున్నారు. నేడు హిందూధర్మ రక్షణ చేయువారమనువారే ఎక్కువ గుర్తింపబడినారు. మేము వ్రాసినది ఏమున్నదని చూడకుండా జ్ఞానమును హేళనగా మాట్లాడినప్పుడు దేవునికి కోపము రాదా! ఎంతోమంది జ్ఞానులైన హిందువులు ఇది గొప్ప జ్ఞానము మా అదృష్టముకొద్దీ ఇంతకాలమునకు దొరికింది అని సంతోషిస్తూవుంటే హిందూధర్మములంటే ఏమిటో తెలియని మూర్ఖులు మేము హిందూ రక్షకులమని చెప్పుచూ, ఏ జ్ఞానమూ తెలియనివారై జ్ఞానమును గురించీ, గ్రంథరూపములలోయున్న జ్ఞానమును గురించీ దూషించి మాట్లాడితే అది ప్రత్యేకమైన కర్మాతీత పాపముకాక ఏమౌతుంది. భగవద్గీతలో క్షరాక్షర పురుషోత్తములుగా దేవుడు తనను గూర్చి వర్ణించి చెప్పితే, త్రైత సిద్ధాంతము ద్వారా ఆ విషయమును మేము చెప్పినప్పుడు ఇది అద్వైతము, ద్వైతములాగ త్రైతము హిందూమతములోనిదే అను పరిజ్ఞానము లేకుండా త్రైత సిద్ధాంత భగవద్గీతను మేము ఒప్పుకోము అని కాల్చినవారిని మేము భక్తిపరులమే అంటే దేవుడు ఒప్పుకుంటాడా! జ్ఞానము అంటే ఏమిటి, అది ఎంత శక్తివంతమైనదని ఏమాత్రము తెలియకుండా మేము మంచివారమే మేము హిందూ రక్షకులమే అంటే దేవుడు ఒప్పుకుంటాడా? అంతటా నిండియున్న దేవుని ముందరే ఆయన గీతను కాల్చినవారినీ, ఆయన జ్ఞానమును దూషించిన వారినీ వదలకుండా రాబోవు కాలములలో ఎప్పుడో ఒకమారు తప్పుకు తగిన శిక్షవేయకమానడు. మాచేత వ్రాయబడిన గ్రంథములు కొన్ని శక్తివంతమై ప్రత్యక్షముగా కనిపిస్తున్నవి. గ్రంథమును చదివితే ఎంతో జ్ఞానశక్తి కల్గుచున్నది. దగ్గరుంచుకొంటే కొన్ని రోగములు సహితము దూరమగుచున్నవి. 48 పేజీలుగల “మంత్రము-మహిమ” అను చిన్న గ్రంథమే దగ్గరుంచితే తేలునొప్పిని నిమిషములో లాగివేయుచున్నది. ఇంత ప్రత్యక్షముగా ఒక గ్రంథమేయుంటే దానికంటే పెద్దగయున్న కొన్ని గ్రంథములలో ఎంతో దైవశక్తియున్నది. భగవద్గీత అన్నిటికంటే మించిన శక్తికలది. అటువంటి వాటిని దూషించితే దాని ఫలితమెట్లుంటుందో తెలివైనవారు ఊహించు కోవచ్చును. “సృష్టికర్త కోడ్ 666” యని క్రైస్తవులు వ్రాస్తే వారికి వ్యతిరేఖముగా అది మాయ కోయని దేవునికోడ్ ఇదియని 9 6 3 ను మేము వ్రాస్తే అది ఏమిటి 64 పేజీలుగల ఆ గ్రంథములో ఏముంది అని చూడక గ్రుడ్డిగా జ్ఞానమును దూషించినవారికి వారికి పడిన శిక్షే పడుతుందని హైదరాబాద్ వస్తున్న బస్సు ప్రమాదము సాక్షిగా నిలచినది. మీరెలా చెప్పగలరని మీ మాట వాస్తవమని మేము నమ్ముటకు ఆధారమేమి యని ఎవరైనా అడిగితే వారికి మేము చెప్పునదేమనగా! దేవునికి అందరూ సమానమే ప్రపంచ సంబంధ కర్మలు ఎలాయున్నా అవి కేవలము కష్ట సుఖములతోనే తీరిపోతాయి. అయితే దేవుని సంబంధమైనవి ఘోరముగా ఉంటాయి. అవి ఒక జన్మకే పరిమితికావు. రెండు యుగముల పర్యంతము జన్మజన్మలకు బాధించును.
